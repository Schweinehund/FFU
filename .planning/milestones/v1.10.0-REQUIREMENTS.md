## v1 Requirements

Requirements for v1.10.0 release. Each maps to roadmap phases.

### Critical Bug Fixes (BUGFIX)

- [x] **BUGFIX-01**: Parallel Winget app updates complete without JSON corruption (file locking/mutex on WinGetWin32Apps.json) — Validated v1.10.0
- [x] **BUGFIX-02**: PPKG files with spaces in filenames copy successfully during deployment and USB creation (xcopy quoting) — Validated v1.10.0
- [x] **BUGFIX-03**: MSI installers with spaces in paths execute without "file not found" errors (path quoting) — Validated v1.10.0
- [x] **BUGFIX-04**: Build skips CU download when ESD image version already matches or exceeds available CU version — Validated v1.10.0

### Winget Improvements (WINGET)

- [x] **WINGET-01**: Apps install in exact order specified in AppList.json (not hash/alphabetical order) — Validated v1.10.0
- [x] **WINGET-02**: Win32 app dependencies automatically resolved and deduplicated before installation — Validated v1.10.0

### Download Improvements (DL)

- [x] **DL-01**: ESD downloads use BITS transfer for reliability (Start-BitsTransferWithRetry) — Validated v1.10.0

### Path Reliability (PATH)

- [x] **PATH-01**: SUBST virtual drive mapped during driver operations to prevent long path (>260 char) failures — Validated v1.10.0

### Deployment Improvements (DEPLOY)

- [x] **DEPLOY-01**: Multiple physical disks present an interactive selection menu instead of defaulting to disk 0 — Validated v1.10.0
- [x] **DEPLOY-02**: 30-second delay in audit mode allows Windows Security Platform to initialize before app installations — Validated v1.10.0
- [x] **DEPLOY-03**: Empty driver folders automatically skipped during deployment with log message — Validated v1.10.0

### Driver Improvements (DRV)

- [x] **DRV-01**: Dell driver download uses CatalogIndexPC for efficient driver package selection — Validated v1.10.0
- [x] **DRV-02**: Model names normalized to remove duplicate brand prefixes (e.g., "Dell Dell Latitude" to "Dell Latitude") — Validated v1.10.0
- [x] **DRV-03**: SystemID extraction from BIOS/WMI works correctly across HP, Dell, and Lenovo — Validated v1.10.0
- [x] **DRV-04**: 8 new OEM manufacturers supported (Panasonic, Fujitsu, Getac, Dynabook, Samsung, Acer, ASUS, MSI) — Validated v1.10.0
- [x] **DRV-05**: Generic/family-level driver fallback attempted when no exact model match found — Validated v1.10.0
- [x] **DRV-06**: PE driver copy operations retry on transient failures with logging — Validated v1.10.0
- [x] **DRV-07**: Driver source selection UI clearly indicates which source is used and why — Validated v1.10.0

### Nice-to-Have (NICE)

- [x] **NICE-01**: USB drive identification uses UniqueId instead of SerialNumber for reliability — Validated v1.10.0
- [x] **NICE-02**: Deployment supports "skip driver installation" option for driver-free scenarios — Validated v1.10.0
