   - Service not found: "Hyper-V is not installed. Run: Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All -NoRestart"

1. Add `Remediation` array to the return hashtable

   - vmrun not found: "vmrun.exe not found in VMware installation. Reinstall VMware Workstation or verify installation path."
   - Version too old: "VMware Workstation version is below 17.0. Consider upgrading for best compatibility."
3. Add `ErrorCode` to classify the issue type (e.g., 'VMWARE_NOT_INSTALLED', 'VMWARE_VMRUN_MISSING', 'VMWARE_VERSION_OLD')

Keep existing functionality intact - this is additive enhancement.
