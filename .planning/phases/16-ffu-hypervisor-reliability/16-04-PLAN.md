Create a new public function `Test-HypervisorService` that checks hypervisor service health.

Function signature:
```powershell
function Test-HypervisorService {
    [CmdletBinding()]
    [OutputType([hashtable])]
    param(
        [Parameter(Mandatory = $true)]
        [ValidateSet('HyperV', 'VMware')]
        [string]$Provider,

        [Parameter(Mandatory = $false)]
        [switch]$WaitForReady,

        [Parameter(Mandatory = $false)]
        [int]$TimeoutSeconds = 60
    )
}
```

Implementation:
1. Return hashtable with:
   - `IsHealthy`: boolean - true if service is ready for operations
   - `ServiceStatus`: string - 'Running', 'Stopped', 'Starting', etc.
   - `CanRecover`: boolean - true if service can be started automatically
   - `RecoveryAction`: string - command/action to recover (e.g., "Start-Service vmms")
   - `LastCheckTime`: datetime

2. For Hyper-V:
   - Check `vmms` (Virtual Machine Management) service status
   - Check `vmcompute` (Hyper-V Host Compute Service) if available (Windows Server)
   - Service must be 'Running' to be healthy
   - CanRecover is true if service exists but stopped
   - RecoveryAction: "Start-Service vmms"

3. For VMware:
   - Check for vmware-vmx.exe processes (indicates VMware is operational)
   - Check VMware Authorization Service (VMAuthdService) if exists
   - Check if vmrun.exe is accessible
   - IsHealthy if vmrun is accessible (VMware doesn't require running service for vmrun)
   - RecoveryAction: Note that VMware is self-recovering, suggest restart of VM if needed

4. WaitForReady behavior:
   - If service not healthy and WaitForReady specified, poll every 1 second up to TimeoutSeconds
   - Log: "Waiting for $Provider service to become ready..."
   - Return after service becomes healthy or timeout

5. Use WriteLog for all status messages.
  </action>

```powershell
$result.Keys | Should -Contain 'ServiceStatus'

```

  </files>
  <action>
Create a retry wrapper function for hypervisor operations that handles service interruptions.

Function signature:
```powershell
function Invoke-WithHypervisorRetry {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory = $true)]
        [scriptblock]$ScriptBlock,

        [Parameter(Mandatory = $true)]
        [ValidateSet('HyperV', 'VMware')]
        [string]$Provider,

        [Parameter(Mandatory = $false)]
        [int]$MaxRetries = 3,

        [Parameter(Mandatory = $false)]
        [int]$BaseDelaySeconds = 5,

        [Parameter(Mandatory = $false)]
        [string]$OperationName = 'Hypervisor operation',

        [Parameter(Mandatory = $false)]
        [switch]$PreCheckService
    )
}
```

Implementation:
1. If PreCheckService specified, call Test-HypervisorService first:
   - If not healthy, wait for ready (up to 60 seconds)
   - If still not healthy, throw with recovery guidance

2. Execute ScriptBlock in try-catch:
   - On success, return result
   - On failure, check if error indicates service issue:
     - Hyper-V: "The Virtual Machine Management Service is not running", "Hyper-V Manager reported an error", RPC errors
     - VMware: "Unable to connect", "vmrun.exe", process not found errors
   - If service issue detected:
     a. Log: "$OperationName failed (attempt $n/$MaxRetries): Service may have restarted"
     b. Call Test-HypervisorService -WaitForReady
     c. If service becomes ready, retry with exponential backoff
     d. Delay = BaseDelaySeconds * (2 ^ (attempt - 1)) with jitter
   - If NOT a service issue, rethrow immediately (don't retry non-transient errors)

3. After max retries exhausted:
   - Log all attempt times and error messages
   - Include service status in final error
   - Include recovery action suggestion
   - Throw comprehensive error

4. Return result from ScriptBlock on success.

5. Example usage in provider methods:
```powershell
Invoke-WithHypervisorRetry -Provider 'HyperV' -OperationName 'StartVM' -ScriptBlock {
    Start-VM -Name $VM.Name -ErrorAction Stop
}
```
  </action>
  <verify>
```powershell

$params.Keys | Should -Contain 'ScriptBlock'
$params.Keys | Should -Contain 'MaxRetries'
$params.Keys | Should -Contain 'PreCheckService'
```
  </verify>
  <done>
Invoke-WithHypervisorRetry wraps operations with automatic retry on service interruptions.
  </done>
