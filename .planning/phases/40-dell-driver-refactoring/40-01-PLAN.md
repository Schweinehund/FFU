<objective>
Implement three internal helper functions in FFU.Drivers.psm1 for CatalogIndexPC-based Dell driver selection, and integrate them into Get-DellDrivers with a three-tier fallback to CatalogPC.cab.

Purpose: Replace the current approach of always downloading the full 160MB CatalogPC.cab with a two-tier catalog architecture: download the lightweight CatalogIndexPC.cab (~5-10MB) first to identify the model-specific cab URL (~1-5MB), achieving a 10-30x reduction in download size per model. The fallback to CatalogPC.cab ensures builds never break due to Dell URL changes.

Output: Updated FFU.Drivers.psm1 with three new internal helpers and CatalogIndexPC integration in Get-DellDrivers. Updated FFU.Constants.psm1 with new URL constant. Windows Server path unchanged.

Scope rationale: This plan has 5 tasks, which is borderline. Tasks 1-4 are simple prerequisite functions (each ~15 min), while Task 5 is the primary integration complexity (~30 min). Tasks 1-4 are lightweight setup; Task 5 is the real work. Splitting further would create artificial plan boundaries between tightly-coupled functions.
</objective>

```powershell
function Get-DellClientModels {
    [CmdletBinding()]
    [OutputType([System.Collections.Generic.List[PSCustomObject]])]
    param(
        [Parameter(Mandatory)]
        [string]$CatalogIndexPath
    )
```

**Logic:**
1. Validate `$CatalogIndexPath` exists, throw if not
2. Create `[System.Collections.Generic.List[PSCustomObject]]` to accumulate results
3. Use XmlReader with ReadSubtree() pattern (same pattern as existing Get-DellDriversModelList in FFUUI.Core.Drivers.Dell.psm1 lines 90-186):
   - Create `XmlReaderSettings` with `IgnoreWhitespace = $true`, `IgnoreComments = $true`
   - Create `XmlReader` on `$CatalogIndexPath`
   - Loop: `while ($reader.Read())` looking for `SystemConfiguration` elements
   - For each `SystemConfiguration`, use `ReadSubtree()` to load as XmlDocument
   - Extract: `<Model>` node text, `<Brand>` node text (default 'Dell'), `<systemID>` node text, `<dellSystemCabUrl>` node text
   - Skip entries where Model, systemID, or dellSystemCabUrl are null/empty
   - Add to list as `[PSCustomObject]@{ Make = $brand; Model = $modelDisplay; SystemId = $systemId; CabUrl = $cabUrl }`
4. Dispose reader in `finally` block
5. Return the list sorted by Make, Model

**CatalogIndexPC XML schema** (from research):
```xml
<ManifestIndex>
  <SystemConfiguration>
    <Model>Latitude 7490 (0798)</Model>
    <Brand>Dell</Brand>
    <systemID>0798</systemID>
    <dellSystemCabUrl>https://downloads.dell.com/catalog/Model_Latitude_7490.cab</dellSystemCabUrl>
  </SystemConfiguration>
</ManifestIndex>
```

**Note:** The XPath for Brand should select the immediate child of SystemConfiguration, not `//Brand` (which could match nested brands). Use `$sysDoc.DocumentElement.SelectSingleNode('Brand')` or similar to stay within the subtree context.

```powershell
function Resolve-DellCabUrlFromModel {
    [CmdletBinding()]
    [OutputType([string])]
    param(
        [Parameter(Mandatory)]
        [string]$ModelDisplay,

        [Parameter(Mandatory)]
        [string]$CatalogIndexPath
    )
```

**Logic:**
1. Extract SystemID from `$ModelDisplay` using the Phase 39 regex pattern: `'\(([0-9A-Fa-f]{4})\)\s*$'`
   - If no match: log `WARNING: No SystemID found in model name '$ModelDisplay'. Falling back to CatalogPC.cab`, return `$null`
   - If match: extract `$systemId = $matches[1]`, log informational message: `WriteLog "Extracted SystemID '$systemId' from model '$ModelDisplay'"`
2. Call `Get-DellClientModels -CatalogIndexPath $CatalogIndexPath` to get all models
3. Search for exact SystemId match: `$match = $models | Where-Object { $_.SystemId -eq $systemId } | Select-Object -First 1`
4. If match found: log `WriteLog "Resolved model-specific cab URL from CatalogIndexPC for SystemID '$systemId': $($match.CabUrl)"`, return `$match.CabUrl`
5. If no match: log `WARNING: SystemID '$systemId' not found in CatalogIndexPC. Falling back to CatalogPC.cab`, return `$null`

**Pattern reuse:** This is the same SystemID regex from Phase 39 (`'\(([0-9A-Fa-f]{4})\)\s*$'`). The model display name from CatalogPC.cab entries (used by Get-DellDriversModelList) includes the trailing `(XXXX)` SystemID.
