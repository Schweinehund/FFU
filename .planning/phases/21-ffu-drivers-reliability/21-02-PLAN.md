  <action>
    Create Get-DriverExtractionResult function to classify vendor-specific extraction exit codes.

    **Function signature:**
    ```powershell
    function Get-DriverExtractionResult {
        [CmdletBinding()]
        [OutputType([PSCustomObject])]
        param(
            [Parameter(Mandatory)]
            [ValidateSet('Dell', 'HP', 'Lenovo', 'Microsoft')]
            [string]$Vendor,

            [Parameter(Mandatory)]
            [int]$ExitCode,

            [Parameter()]
            [string]$DriverName = 'Unknown'
        )
    }
    ```

    **Return object:**
    ```powershell
    [PSCustomObject]@{
        Success     = [bool]   # True if extraction succeeded (even with reboot required)
        Critical    = [bool]   # True if failure should halt build
        Message     = [string] # Human-readable description
        Action      = [string] # 'Continue', 'Warn', 'Fail'
    }
    ```

    **Exit code classifications:**

    **HP softpaq exit codes:**
    - 0 = Success (Action: Continue)
    - 1 = General error - often non-critical (Action: Warn, Continue)
    - 2 = Invalid command line (Action: Fail)
    - 3 = Initialization error (Action: Warn, Continue)
    - 1641 = Success, reboot initiated (Action: Continue - we don't want reboot)
    - 3010 = Success, reboot required (Action: Continue - normal for driver installers)

    **Lenovo extraction exit codes:**
    - 0 = Success (Action: Continue)
    - 1 = General error (Action: Warn, Continue)
    - 2 = Invalid parameter (Action: Fail)
    - 3 = File not found (Action: Fail)
    - 5 = Access denied (Action: Fail)
    - 1603 = Fatal error during installation (Action: Warn, Continue)
    - 3010 = Success, reboot required (Action: Continue)

    **Dell exit codes (existing timeout handling):**
    - 0 = Success (Action: Continue)
    - 1 = General error (Action: Warn, Continue)
    - 2 = Invalid parameter (Action: Fail)
    - Timeout = Process killed (Action: Warn, Continue - drivers likely extracted)

    **Microsoft (MSI admin install):**
    - 0 = Success (Action: Continue)
    - 1601-1603 = Installation errors (Action: Warn, Continue)
    - 1618 = Another installation in progress (Action: Warn, Continue)
    - 3010 = Success, reboot required (Action: Continue)

    **Default for unknown codes:**
    - Any other code: Action = 'Warn', Continue (non-critical by default per prior decision)

    **Implementation:**
    ```powershell
    $result = [PSCustomObject]@{
        Success  = $false
        Critical = $false
        Message  = ''
        Action   = 'Continue'
    }

    switch ($Vendor) {
        'HP' {
            switch ($ExitCode) {
                0       { $result.Success = $true; $result.Message = "HP $DriverName extracted successfully" }
                1       { $result.Message = "HP $DriverName extraction warning (general error)"; $result.Action = 'Warn' }
                2       { $result.Critical = $true; $result.Message = "HP $DriverName: Invalid command line"; $result.Action = 'Fail' }
                3       { $result.Message = "HP $DriverName initialization error (non-critical)"; $result.Action = 'Warn' }
                1641    { $result.Success = $true; $result.Message = "HP $DriverName extracted (reboot initiated - ignored)" }
                3010    { $result.Success = $true; $result.Message = "HP $DriverName extracted (reboot required - expected)" }
                default { $result.Message = "HP $DriverName unknown exit code $ExitCode (continuing)"; $result.Action = 'Warn' }
            }
        }
        # ... similar for Lenovo, Dell, Microsoft
    }

    return $result
    ```

    Place function after Invoke-DriverDownloadWithRetry (if 21-01 is complete) or after using statement.
    This is an internal helper function - do NOT add to FunctionsToExport.

  <files>

  <action>
    Update Get-HPDrivers and Get-LenovoDrivers to use Get-DriverExtractionResult for exit code handling.

    **Get-HPDrivers extraction (lines ~666-674):**
    Currently uses Invoke-Process which throws on failure. Update to capture exit code:
    ```powershell
    # Before:
    try {
        Invoke-Process -FilePath $DriverFilePath -ArgumentList $arguments -ErrorAction Stop | Out-Null
        WriteLog "Driver extracted to: $extractFolder"
    }
    catch {
        WriteLog "WARNING: Failed to extract HP driver '$Name': $($_.Exception.Message)"
    }

    # After:
    try {
        $process = Start-Process -FilePath $DriverFilePath -ArgumentList $arguments -PassThru -Wait -NoNewWindow
        $result = Get-DriverExtractionResult -Vendor 'HP' -ExitCode $process.ExitCode -DriverName $Name

        if ($result.Action -eq 'Warn') {
            WriteLog "WARNING: $($result.Message)"
        }
        elseif ($result.Action -eq 'Fail') {
            WriteLog "ERROR: $($result.Message)"
            continue  # Skip to next driver, don't halt entire build
        }
        else {
            WriteLog "Driver extracted to: $extractFolder"
        }
    }
    catch {
        WriteLog "WARNING: Failed to extract HP driver '$Name': $($_.Exception.Message)"
    }
    ```

    **Get-LenovoDrivers extraction (lines ~1027-1034):**

    # After existing code that sets $completed and checks timeout:

    Describe 'REL-DRV-02: Vendor-Specific Extraction Error Handling' -Tag 'Unit', 'FFU.Drivers', 'Reliability' {

            It 'Should classify HP exit code 3010 as success (reboot required)' {
                $result = & $getResult -Vendor 'HP' -ExitCode 3010 -DriverName 'TestDriver'
                $result.Success | Should -BeTrue

            It 'Should classify HP exit code 1 as warning (non-critical)' {
                $result = & $getResult -Vendor 'HP' -ExitCode 1 -DriverName 'TestDriver'
                $result.Action | Should -Be 'Warn'

            }

            It 'Should classify HP exit code 2 as critical failure' {
                $result = & $getResult -Vendor 'HP' -ExitCode 2 -DriverName 'TestDriver'
                $result.Action | Should -Be 'Fail'
                $result.Critical | Should -BeTrue

            It 'Should classify Lenovo exit code 0 as success' {
                $result = & $getResult -Vendor 'Lenovo' -ExitCode 0 -DriverName 'TestDriver'
