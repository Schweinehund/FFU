Implement a comprehensive Preflight Dashboard integrated with C# services that runs PowerShell Test-FFU* functions, parses results, displays checks grouped by category, and provides one-click repair for repairable issues.

Purpose: Provide users with immediate environment readiness assessment and self-healing capability before builds start, eliminating failed builds due to preventable environment issues.

Output: Working Dashboard tab with live preflight checks, color-coded status display, and automated repair invocation via PowerShell SDK.
</objective>

  <files>FFUApplication/Services/PreflightService.cs</files>
  <action>
Create PreflightService with two public methods:
- `async Task<List<PreflightCheck>> RunAllChecksAsync()` — Invokes all Test-FFU* functions via PowerShell SDK, parses JSON results into PreflightCheck models. Catches exceptions per check (not global) so individual test failures don't prevent others from running. Each check exception is logged with check name for diagnostics.
- `async Task<bool> RepairCheckAsync(string checkName)` — Invokes corresponding Repair-FFU* function from SafeRepairMap (only 4 repairable: WimMount→Repair-FFUWimMount, DISMState→Repair-FFUDismState, DISMCleanup→Invoke-FFUDISMCleanup, Network→Repair-FFUNetwork). Returns success status.

Implement fault tolerance using try-catch per check, not per batch. Each check result includes:
- checkName (exact name from static map)
- category (from CategoryMap)
- status (Passed, Failed, Warning)
- timestamp
- message (from Test output or error message)

Use PowerShellSDKHelper (from Phase 49) for all SDK calls. Map PowerShell JSON output to C# PreflightCheck models.
