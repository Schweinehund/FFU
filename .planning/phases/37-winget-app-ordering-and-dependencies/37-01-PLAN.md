Add four new helper functions at the TOP of FFU.Common.Winget.psm1, BEFORE the existing `function Get-Application` definition. These are module-internal functions (NOT exported). Follow the exact implementations from 37-RESEARCH.md.

**1. Get-WinGetWin32AppsJsonMutexName**
- Accepts `[string]$WinGetWin32AppsJsonPath` (Mandatory)
- Computes SHA256 hash of the full path: `$hashBytes = [System.Security.Cryptography.SHA256]::Create().ComputeHash([System.Text.Encoding]::UTF8.GetBytes($WinGetWin32AppsJsonPath))`
- Returns string: `"WinGetWin32Apps_$hashHex"` where hashHex is first 16 chars of hex-encoded hash
- This ensures unique mutex names per JSON file path (replaces hardcoded "WinGetWin32AppsJsonLock")

**2. Invoke-WithNamedMutex**
- Accepts `[string]$MutexName` (Mandatory), `[scriptblock]$ScriptBlock` (Mandatory), `[int]$TimeoutSeconds = 60`
- Creates `New-Object System.Threading.Mutex($false, $MutexName)`
- Calls `$mutex.WaitOne([TimeSpan]::FromSeconds($TimeoutSeconds))` -- throws if timed out
- Invokes `& $ScriptBlock` (call operator, inherits parent scope)
- Finally block: releases mutex if taken (try/catch around ReleaseMutex), disposes mutex
- See 37-RESEARCH.md Pattern 1 for exact implementation

**3. Set-FileContentAtomic**
- Accepts `[string]$Path` (Mandatory), `[string]$Content` (Mandatory)
- Creates parent directory if missing
- Writes to temp file: `"$Path.$([guid]::NewGuid().ToString('N')).tmp"`
- Uses `[System.IO.File]::Move($tempPath, $Path, $true)` with fallback to `Move-Item -Force`
- See 37-RESEARCH.md Pattern 2 for exact implementation

**4. Get-WinGetYamlScalarValue**
- Accepts `[string]$YamlText` (Mandatory), `[string]$Key` (Mandatory)
- Uses regex to extract simple YAML scalar values: `"(?m)^${Key}:\s+(.+)$"`
- Returns the matched value trimmed, or `$null` if not found
- Strip surrounding quotes (single and double) from the value

**D. Upgrade deduplication** -- inside the mutex scriptblock, REPLACE the existing name-based duplicate check with two-tier dedup:

```powershell
# De-dupe by PackageIdentifier first, then by command+args
$isDuplicate = $false
if (-not [string]::IsNullOrWhiteSpace($PackageIdentifier)) {
    $existingById = $appsData | Where-Object {
        $_.PSObject.Properties['PackageIdentifier'] -and
        $_.PackageIdentifier -eq $PackageIdentifier
    } | Select-Object -First 1
    if ($existingById) {
        $isDuplicate = $true
        WriteLog "Skipping duplicate Win32 install entry: Name='$appNameToCheck' PackageIdentifier='$PackageIdentifier'"
    }
}
if (-not $isDuplicate) {
    # Fall back to existing name-based check
    if ($appsData | Where-Object { $_.Name -eq $appNameToCheck }) {
        $isDuplicate = $true
        WriteLog "App '$appNameToCheck' already in WinGetWin32Apps.json (checked inside lock)"
    }
}
if (-not $isDuplicate) {
    # Also check by CommandLine + Arguments
    $existingByCommand = $appsData | Where-Object {
        $_.PSObject.Properties['CommandLine'] -and
        $_.PSObject.Properties['Arguments'] -and
        $_.CommandLine -eq $silentInstallCommand -and
        $_.Arguments -eq $silentInstallSwitch
    } | Select-Object -First 1
    if ($existingByCommand) {
        $isDuplicate = $true
        WriteLog "Skipping duplicate Win32 install entry by command match: Name='$appNameToCheck'"
    }
}
if ($isDuplicate) {
    return @{ Added = $false; Reason = 'Duplicate' }
}
```

**A. Upgrade Get-Apps override section mutex/write pattern:**

In the `Get-Apps` function, find the override section (around line 452-509) that applies AppList.json command overrides to WinGetWin32Apps.json. Replace the raw mutex pattern:

Replace:
```powershell
$lockName = "WinGetWin32AppsJsonLock"
$lock = New-Object System.Threading.Mutex($false, $lockName)
try {
    [void]$lock.WaitOne()
    # ... override logic ...
}
finally {
    $lock.ReleaseMutex()
    $lock.Dispose()
}
```

With:
```powershell
$mutexName = Get-WinGetWin32AppsJsonMutexName -WinGetWin32AppsJsonPath $winGetWin32Path
Invoke-WithNamedMutex -MutexName $mutexName -TimeoutSeconds 60 -ScriptBlock {
    # Re-read content inside lock to ensure latest version
    [array]$appsDataUpdated = Get-Content -Path $winGetWin32Path -Raw | ConvertFrom-Json
    $changed = $false
    foreach ($entry in $appsDataUpdated) {
        if ($overrideMap.ContainsKey($entry.Name)) {
            $ov = $overrideMap[$entry.Name]
            if ($ov.CommandLine) {
                WriteLog "Override (AppList.json) CommandLine for $($entry.Name)"
                $entry.CommandLine = $ov.CommandLine
                $changed = $true
            }
            if ($ov.Arguments) {
                WriteLog "Override (AppList.json) Arguments for $($entry.Name)"
                $entry.Arguments = $ov.Arguments
                $changed = $true
            }
            if ($ov.ContainsKey('AdditionalExitCodes') -and $null -ne $ov.AdditionalExitCodes) {
                WriteLog "Override (AppList.json) AdditionalExitCodes for $($entry.Name)"
                $entry | Add-Member -NotePropertyName AdditionalExitCodes -NotePropertyValue $ov.AdditionalExitCodes -Force
                $changed = $true
            }
            if ($ov.ContainsKey('IgnoreNonZeroExitCodes') -and $null -ne $ov.IgnoreNonZeroExitCodes) {
                WriteLog "Override (AppList.json) IgnoreNonZeroExitCodes for $($entry.Name)"
                $entry | Add-Member -NotePropertyName IgnoreNonZeroExitCodes -NotePropertyValue ([bool]$ov.IgnoreNonZeroExitCodes) -Force
                $changed = $true
            }
        }
    }
    if ($changed) {
        $jsonText = $appsDataUpdated | ConvertTo-Json -Depth 10
        Set-FileContentAtomic -Path $winGetWin32Path -Content $jsonText
        WriteLog "Applied AppList.json command overrides to WinGetWin32Apps.json"
    }
    else {
        WriteLog "No matching apps required command overrides."
    }
}
```

Key changes:
1. `New-Object System.Threading.Mutex` -> `Invoke-WithNamedMutex` with path-based mutex name
2. `Set-Content` -> `Set-FileContentAtomic`
3. Variables `$winGetWin32Path`, `$overrideMap` are defined BEFORE the mutex call (scope inheritance via `&` operator)
