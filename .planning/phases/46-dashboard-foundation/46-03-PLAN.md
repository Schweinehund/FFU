**Start-DashboardChecks function:**

Create a script-scoped function `Start-DashboardChecks` that:

1. Shows progress panel: `$script:uiState.Controls.pnlDashboardProgress.Visibility = 'Visible'`
2. Disables refresh button: `$script:uiState.Controls.btnRefreshChecks.IsEnabled = $false`
3. Clears previous results: Call `Clear-DashboardResults -State $script:uiState`
4. Sets summary to "Checking system readiness...": `$script:uiState.Controls.txtSummaryStatus.Text = 'Checking system readiness...'`
5. Creates messaging context if needed: `if ($null -eq $script:uiState.Data.dashboardMessagingContext) { $script:uiState.Data.dashboardMessagingContext = New-FFUMessagingContext }`
6. Gathers current feature selections from UI checkboxes into a $features hashtable:
   ```
   $features = @{
       CreateVM = $true  # Always check VM readiness
       CreateCaptureMedia = [bool]$script:uiState.Controls.chkCreateCaptureMedia.IsChecked
       CreateDeploymentMedia = [bool]$script:uiState.Controls.chkCreateDeploymentMedia.IsChecked
       InstallApps = [bool]$script:uiState.Controls.chkInstallApps.IsChecked
       UpdateLatestCU = [bool]$script:uiState.Controls.chkLatestCU.IsChecked
       DownloadDrivers = [bool]$script:uiState.Controls.chkDownloadDrivers.IsChecked
   }
   ```
7. Determines hypervisor type from UI (`$script:uiState.Controls.cmbHypervisorType.SelectedItem` or equivalent).
8. Launches background job via Start-ThreadJob:
   ```powershell
   $script:uiState.Data.currentDashboardJob = Start-ThreadJob -ScriptBlock {
       param($context, $features, $ffuPath, $hypervisorType)

       # Add module path
       $modulePath = Join-Path $ffuPath 'Modules'
       if ($env:PSModulePath -notlike "*$modulePath*") {
           $env:PSModulePath = "$modulePath;$env:PSModulePath"
       }

       Import-Module FFU.Preflight -Force
       Import-Module FFU.Messaging -Force

       try {
           Write-FFUMessage -Context $context -Message "DASHBOARD_STARTED" -Level Info

           $result = Invoke-FFUPreflight -Features $features `
               -FFUDevelopmentPath $ffuPath `
               -HypervisorType $hypervisorType `
               -SkipCleanup `
               -ErrorAction Stop

           # Send individual check results
           $checkNum = 0
           $allTiers = @('Tier1Results', 'Tier2Results', 'Tier3Results')
           $totalChecks = 0
           foreach ($tier in $allTiers) {
               $totalChecks += $result.$tier.Count
           }

           foreach ($tier in $allTiers) {
               foreach ($checkName in $result.$tier.Keys) {
                   $checkNum++
                   $check = $result.$tier[$checkName]

                   # Send progress
                   Write-FFUMessage -Context $context `
                       -Message "DASHBOARD_PROGRESS|$checkNum|$totalChecks|$checkName" -Level Info

                   # Send check result (use pipe-delimited format)
                   $severity = if ($check.PSObject.Properties['Severity']) { $check.Severity } else { 'Info' }
                   $remediation = if ($check.PSObject.Properties['Remediation']) { $check.Remediation } else { '' }
                   # Replace pipes in message/remediation to avoid delimiter collision
                   $safeMsg = ($check.Message -replace '\|', ' - ')
                   $safeRemed = ($remediation -replace '\|', ' - ')

                   Write-FFUMessage -Context $context `
                       -Message "DASHBOARD_CHECK|$checkName|$($check.Status)|$severity|$safeMsg|$safeRemed" -Level Info
               }
           }

           # Send completion with counts
           Write-FFUMessage -Context $context `
               -Message "DASHBOARD_COMPLETE|$($result.CriticalCount)|$($result.WarningCount)|$totalChecks|$checkNum" -Level Info
       }
       catch {
           Write-FFUMessage -Context $context `
               -Message "DASHBOARD_ERROR|Pre-flight checks failed: $($_.Exception.Message)" -Level Error
       }
   } -ArgumentList $script:uiState.Data.dashboardMessagingContext, $features, $FFUDevelopmentPath, $hypervisorType
   ```

**DispatcherTimer polling:**

Create a DispatcherTimer at 50ms interval that polls the dashboard messaging context. Store it in `$script:uiState.Data.dashboardPollTimer`.

The Tick handler should:
1. Return early if `$script:uiState.Data.dashboardMessagingContext` is null
2. Loop `while ($script:uiState.Data.dashboardMessagingContext.MessageQueue.TryDequeue([ref]$msg))`:
   - Parse `$msg.Message` by prefix:
   - `DASHBOARD_STARTED`: (no action needed, progress already shown)
   - `DASHBOARD_PROGRESS|{num}|{total}|{name}`: Update `txtDashboardProgressStatus.Text = "Running check $num of ${total}: $name..."`
   - `DASHBOARD_CHECK|{name}|{status}|{severity}|{message}|{remediation}`: Call `Update-DashboardCheckUI -State $script:uiState -CheckName $name -Status $status -Severity $severity -Message $message -Remediation $remediation`
   - `DASHBOARD_COMPLETE|{criticalCount}|{warningCount}|{totalChecks}|{passedChecks}`:
     - Hide progress: `$script:uiState.Controls.pnlDashboardProgress.Visibility = 'Collapsed'`
     - Enable refresh: `$script:uiState.Controls.btnRefreshChecks.IsEnabled = $true`
     - Calculate passed checks: $totalChecks - $criticalCount - $warningCount
     - Call `Update-SummaryStatus` with counts
     - Call `Update-BuildButtonState` with counts
     - Update category summaries by iterating each category and counting checks in panels
     - Reorder categories: Move Expanders with failures to top of stackDashboardContainer, then warnings, then passing (use `$stackPanel.Children.Remove()` + `$stackPanel.Children.Insert()`)
   - `DASHBOARD_ERROR|{message}`: Update summary to error state, hide progress, enable refresh
3. Check if job is complete: `if ($null -ne $script:uiState.Data.currentDashboardJob -and $script:uiState.Data.currentDashboardJob.State -in @('Completed', 'Failed', 'Stopped'))` then clean up job reference

Start the timer immediately.

**IMPORTANT threading notes:**
- Use `[DateTime]::Now` instead of `Get-Date` (ThreadJob compatibility)
- Use `$function:WriteLog` check before calling WriteLog in background job context
- The DispatcherTimer Tick handler runs on the UI thread, so direct UI manipulation is safe

    System = @{ Total = 0; Passed = 0; Failed = 0; Warning = 0 }
    Hypervisor = @{ Total = 0; Passed = 0; Failed = 0; Warning = 0 }
    BuildTools = @{ Total = 0; Passed = 0; Failed = 0; Warning = 0 }
    Network = @{ Total = 0; Passed = 0; Failed = 0; Warning = 0 }

In the DASHBOARD_CHECK handler, after calling Update-DashboardCheckUI, update the stats:
```powershell
$category = Get-CheckCategory -CheckName $checkName
$stats = $script:uiState.Data.dashboardCategoryStats[$category]
$stats.Total++
switch ($status) {
    'Passed'  { $stats.Passed++ }
    'Failed'  { if ($severity -eq 'Critical') { $stats.Failed++ } else { $stats.Warning++ } }
    'Warning' { $stats.Warning++ }
    'Skipped' { $stats.Total--; } # Don't count skipped in totals
}

# Live update category summary as each check completes
Update-CategorySummary -State $script:uiState -Category $category `
    -TotalChecks $stats.Total -PassedChecks $stats.Passed `
    -FailedChecks $stats.Failed -WarningChecks $stats.Warning
```

In the DASHBOARD_COMPLETE handler, perform final category reordering:
```powershell
# Reorder categories: failures first, then warnings, then passing
$container = $script:uiState.Controls.stackDashboardContainer
if ($null -ne $container) {
    # Collect category expanders (skip non-expander children like summary banner, progress, button)
    $expanders = @()
    $nonExpanders = @()
    foreach ($child in @($container.Children)) {
        if ($child -is [System.Windows.Controls.Expander]) {
            $expanders += $child
        } else {
            $nonExpanders += $child
        }
    }

    # Sort: failed categories first, then warning, then passed
    $sortedExpanders = $expanders | Sort-Object {
        $catName = $_.Name -replace '^exp', ''
        $stats = $script:uiState.Data.dashboardCategoryStats[$catName]
        if ($null -eq $stats) { return 2 }
        if ($stats.Failed -gt 0) { return 0 }
        if ($stats.Warning -gt 0) { return 1 }
        return 2
    }

    # Rebuild children: non-expanders first (banner, progress, button), then sorted expanders
    $container.Children.Clear()
    foreach ($item in $nonExpanders) { $container.Children.Add($item) }
    foreach ($exp in $sortedExpanders) { $container.Children.Add($exp) }
}
```

This ensures categories with failures sort to the top after each check run, matching the CONTEXT.md requirement for severity-first ordering.
