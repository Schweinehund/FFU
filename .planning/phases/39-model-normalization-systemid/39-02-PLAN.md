**1. Add Get-NormalizedManufacturer function** (place near other helper functions, before the driver detection section):

```powershell
function Get-NormalizedManufacturer {
    [CmdletBinding()]
    param([string]$RawManufacturer)
    if ([string]::IsNullOrWhiteSpace($RawManufacturer)) { return '' }
    $m = $RawManufacturer.Trim()
    # Canonical manufacturer mapping
    if ($m -match '(?i)^dell') { return 'Dell' }
    if ($m -match '(?i)^(hp\b|hewlett)') { return 'HP' }
    if ($m -match '(?i)^lenovo') { return 'Lenovo' }
    if ($m -match '(?i)^(microsoft|surface)') { return 'Microsoft' }
    return $m
}
```

**2. Add Get-SystemIdentityMetadata function** (place after Get-NormalizedManufacturer):

Returns a structured `[PSCustomObject]` with these properties:
- `ManufacturerNormalized` — canonical manufacturer name from Get-NormalizedManufacturer
- `ModelNormalized` — cleaned model string (trimmed)
- `SystemSkuNormalized` — primary SKU identifier, OEM-specific:
  - Dell: `MS_SystemInformation.SystemSku` (via `Get-CimInstance Win32_ComputerSystem | Select-Object -ExpandProperty SystemSKUNumber`, with `-ErrorAction SilentlyContinue`)
  - HP: `MS_SystemInformation.BaseBoardProduct` (via `Get-CimInstance Win32_BaseBoard | Select-Object -ExpandProperty Product`, with `-ErrorAction SilentlyContinue`)
  - Lenovo: First 4 characters of `Win32_ComputerSystem.Model` (trimmed, uppercased)
  - Other: `$null`
- `FallbackSkuNormalized` — secondary SKU (Dell only):
  - Dell: Parse `Win32_ComputerSystem.OEMStringArray` for bracket-tag patterns like `[www.dell.com]` followed by identifier. Use `Get-CimInstance Win32_ComputerSystem | Select-Object -ExpandProperty OEMStringArray`, search for `\[([^\]]+)\]` patterns, take the value after the tag.
  - Others: `$null`
- `MachineTypeNormalized` — Lenovo machine type: first 4 chars of `Win32_ComputerSystem.Model`, `.Trim().ToUpperInvariant()`. `$null` for non-Lenovo.
- `IdentifierLabel` — human-readable label for the identifier type: "SystemSKU" (Dell), "BaseBoardProduct" (HP), "MachineType" (Lenovo), "N/A" (other)
- `IdentifierValue` — the primary identifier value (same as SystemSkuNormalized for Dell/HP, MachineTypeNormalized for Lenovo)

All WMI calls wrapped in try/catch with `-ErrorAction SilentlyContinue`. On failure, fields stay `$null`.
All non-null string values normalized with `.Trim().ToUpperInvariant()`.

Log extracted values: `WriteLog "System Identity: Manufacturer='$manufacturerNorm', Model='$modelNorm', $identifierLabel='$identifierValue'"`.
If a field is null, display "Not Detected" in log output.

**3. Enhance the automatic driver detection section** (the existing `# --- Automatic Driver Detection using DriverMapping.json ---` block):

Currently the matching logic uses manufacturer wildcard + model name comparison. Enhance to also try SystemID/MachineType matching:

a. After getting `$systemManufacturer` and `$systemModel`, call:
   ```powershell
   $systemIdentity = Get-SystemIdentityMetadata
   ```

b. Replace the existing `foreach ($rule in $driverMappings)` matching loop with enhanced matching that tries SystemID/MachineType first:
   ```
   foreach ($rule in $driverMappings):
     # Manufacturer must match
     if NOT ($systemIdentity.ManufacturerNormalized matches Get-NormalizedManufacturer($rule.Manufacturer)):
       continue

     # Try SystemID/MachineType match first (most precise)
     $identifierMatch = $false
     if ($systemIdentity.IdentifierValue -and $rule.PSObject.Properties['SystemId'] -and $rule.SystemId) {
       if ($systemIdentity.IdentifierValue -eq $rule.SystemId.Trim().ToUpperInvariant()) {
         $identifierMatch = $true
         WriteLog "SystemID match: System='$($systemIdentity.IdentifierValue)' == Rule='$($rule.SystemId)'"
       }
     }
     if (-not $identifierMatch -and $systemIdentity.MachineTypeNormalized -and $rule.PSObject.Properties['MachineType'] -and $rule.MachineType) {
       if ($systemIdentity.MachineTypeNormalized -eq $rule.MachineType.Trim().ToUpperInvariant()) {
         $identifierMatch = $true
         WriteLog "MachineType match: System='$($systemIdentity.MachineTypeNormalized)' == Rule='$($rule.MachineType)'"
       }
     }

     # Fall back to model name matching (existing logic)
     $modelMatch = $false
     if (-not $identifierMatch) {
       $ruleModelNorm = ConvertTo-ComparableModelName -Text $rule.Model
       if ($systemModelNorm -like "$($ruleModelNorm)*" -or $ruleModelNorm -like "$systemModelNorm*") {
         $modelMatch = $true
       }
     }

     if ($identifierMatch -or $modelMatch) {
       $matchType = if ($identifierMatch) { "SystemID" } else { "ModelName" }
       WriteLog "Match found ($matchType): Manufacturer='$($rule.Manufacturer)', Model='$($rule.Model)'"
       $matchingRules += [PSCustomObject]@{
         Rule = $rule
         MatchType = $matchType
         MatchPrecision = if ($identifierMatch) { 2 } else { 1 }
       }
     }
   ```

c. Update the best-match selection to prefer SystemID matches over model-name matches:
   ```powershell
   # Sort by match precision (SystemID > ModelName), then by model name length (most specific)
   $matchedRule = ($matchingRules | Sort-Object -Property @{Expression={$_.MatchPrecision}; Descending=$true}, @{Expression={$_.Rule.Model.Length}; Descending=$true} | Select-Object -First 1).Rule
   ```

d. Update the logging to show match type in the output:
   ```powershell
   $bestMatch = $matchingRules | Sort-Object ... | Select-Object -First 1
   $matchedRule = $bestMatch.Rule
   WriteLog "Best match ($($bestMatch.MatchType)): Manufacturer='$($matchedRule.Manufacturer)', Model='$($matchedRule.Model)'"
   ```
