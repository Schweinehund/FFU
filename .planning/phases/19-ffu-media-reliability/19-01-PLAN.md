  <action>
    Create Test-WinPEMediaReadiness function in FFU.Media.psm1. Follow the pattern from Test-FFUCaptureReadiness in FFU.Imaging.

    **Function signature:**
    ```powershell
    function Test-WinPEMediaReadiness {
        [CmdletBinding()]
        [OutputType([PSCustomObject])]
        param(
            [Parameter(Mandatory)]
            [ValidateSet('x64', 'arm64')]
            [string]$Architecture,

            [Parameter(Mandatory)]
            [string]$FFUDevelopmentPath,

            [Parameter(Mandatory)]
            [string]$ADKPath,

            [Parameter()]
            [switch]$CreateCapture,

            [Parameter()]
            [switch]$CreateDeploy,

            [Parameter()]
            [string]$CaptureISOPath,

            [Parameter()]
            [string]$DeployISOPath
        )
    }
    ```

    **Implementation - validate in sequence, fail fast:**
    1. **ADK Prerequisites** - Call Test-ADKPrerequisites with -ThrowOnFailure $false
       - If not valid: return early with FailureReason='ADKValidation'
    2. **WIMMount Service** - Call Test-FFUWimMount -AttemptRemediation
       - If status != 'Passed': return early with FailureReason='WIMMount'
    3. **Architecture Capability** - Check ADK has tools for target architecture
       - Verify oscdimg.exe exists at architecture-specific path
       - Verify winpe.wim exists at architecture-specific path
       - If missing: return with FailureReason='ArchitectureMissing'
    4. **WinPE Working Space** - Call Test-DiskSpaceForOperation (from FFU.Imaging)
       - Path: Join-Path $FFUDevelopmentPath 'WinPE'
       - RequiredBytes: 15GB
       - If insufficient: return with FailureReason='InsufficientSpace'
    5. **ISO Output Space** (if ISO paths provided) - Check destination drives
       - Use Test-DiskSpaceForOperation for CaptureISOPath/DeployISOPath
       - RequiredBytes: 1GB per ISO (estimate)

    **Return object structure:**
    ```powershell
    [PSCustomObject]@{
        Ready         = $true/$false
        FailureReason = $null/'ADKValidation'/'WIMMount'/'ArchitectureMissing'/'InsufficientSpace'/'ISOSpaceInsufficient'
        Message       = "Human-readable description"
        Remediation   = "Steps to fix" (from underlying check)
        Details       = @{
            ADKPath        = $ADKPath
            Architecture   = $Architecture
            ADKVersion     = $adkResult.ADKVersion
            Checks         = @{
                ADK      = $adkResult
                WIMMount = $wimMountResult
                Space    = $spaceCheck
            }
        }
    }
    ```

    **On all checks passed:**
    Return Ready=$true with details about validated components.

    **Export function** in FFU.Media.psd1 FunctionsToExport array.

    **Note:** Use Test-DiskSpaceForOperation from FFU.Imaging (already a dependency through FFU.Core).
  </action>
