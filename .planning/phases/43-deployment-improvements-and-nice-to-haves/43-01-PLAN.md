  <files>FFUDevelopment/WinPEDeployFFUFiles/ApplyFFU.ps1</files>

    **NICE-02: Add skip-driver installation prompt** before driver detection block:
    - Insert a `$skipDrivers = $false` variable BEFORE the `#Find Drivers` comment at line 765
    - After setting up `$DriversPath` (line 766) and checking `Test-Path -Path $DriversPath`, add an interactive Y/N prompt:
      ```
      Write-Host 'Drivers folder detected.'
      do {
          try {
              $var = $true
              $response = Read-Host 'Install drivers? (Y/N)'
              if ($response -match '^[Yy]') { $skipDrivers = $false }
              elseif ($response -match '^[Nn]') {
                  $skipDrivers = $true
                  WriteLog 'User elected to skip driver installation'
                  Write-Host 'Driver installation will be skipped.'
              }
              else { Write-Host 'Please enter Y or N'; $var = $false }
          }
          catch { Write-Host 'Invalid input. Please enter Y or N'; $var = $false }
      } until ($var)
      ```
    - If `$skipDrivers -eq $true`, skip the ENTIRE driver detection block (both automatic DriverMapping.json matching AND manual selection). Set `$DriverSourcePath = $null` immediately and skip to the driver installation section.
    - Ensure Write-SectionHeader 'Drivers Selection' still shows (so user sees the section), but the Y/N prompt appears right after it.

    **DEPLOY-03: Add empty driver folder detection** before the driver installation block:
    - Insert check BEFORE the `# Add Drivers` comment (around line 1192), AFTER driver selection but BEFORE driver injection:
    - Check only when `$DriverSourceType -eq 'Folder'` (WIM files cannot be "empty" without being corrupt):
      ```
      if ($null -ne $DriverSourcePath -and $DriverSourceType -eq 'Folder') {
          $driverInfFiles = Get-ChildItem -Path $DriverSourcePath -Recurse -File -Include *.inf -ErrorAction SilentlyContinue
          if ($null -eq $driverInfFiles -or $driverInfFiles.Count -eq 0) {
              WriteLog "Driver folder '$DriverSourcePath' contains no .inf files. Skipping driver installation."
              Write-Host "Driver folder '$DriverSourcePath' contains no .inf files. Skipping driver installation."
              $DriverSourcePath = $null
          }
          else {
              WriteLog "Found $($driverInfFiles.Count) driver .inf file(s) in '$DriverSourcePath'"
          }
      }
      ```
    - This check uses `-Include *.inf` (the signature file for Windows drivers) and `-Recurse` to handle nested OEM folder structures
    - Setting `$DriverSourcePath = $null` causes the existing `else` block at line 1308 to log "No drivers to install."

    **Integration notes:**
    - The skip-drivers prompt should appear INSIDE the `If (Test-Path -Path $DriversPath)` block, BEFORE the DriverMapping.json automatic detection
    - If user skips, both automatic and manual driver detection are bypassed entirely
    - The empty folder check is a SEPARATE safety net that catches cases where automatic/manual selection chose an empty folder
    - Both checks result in `$DriverSourcePath = $null` which the existing driver installation block already handles gracefully
