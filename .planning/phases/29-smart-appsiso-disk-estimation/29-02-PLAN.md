Function signature:
```powershell
function Test-AppsISOStaleness {
    [CmdletBinding()]
    [OutputType([PSCustomObject])]
    param(
        [Parameter(Mandatory)]
        [string]$AppsISOPath,

        [Parameter(Mandatory)]
        [string]$AppsPath,

        [Parameter(Mandatory)]
        [hashtable]$CurrentConfig
    )
}
```

Implementation with three tiers:

**Tier 1: ISO existence check**
- If ISO does not exist: return `@{ Stale = $true; Reason = "Apps.iso does not exist"; Action = "Create"; Details = @() }`

**Tier 2: Manifest existence and config comparison**
- Call `Get-AppsContentManifest -AppsPath $AppsPath`
- If manifest is null: return `@{ Stale = $true; Reason = "No content manifest found - first build or manifest deleted"; Action = "Rebuild"; Details = @() }`
- Compare ConfigState keys (InstallOffice, UpdateLatestDefender, UpdateLatestMSRT, UpdateEdge, UpdateOneDrive)
- For each key that differs: add to $changedConfigs array
- If $changedConfigs.Count -gt 0: return `@{ Stale = $true; Reason = "Configuration changed"; Action = "Rebuild"; Details = $changedConfigs }`

**Tier 3: File hash comparison**
- Generate current manifest: `$currentManifest = New-AppsContentManifest -AppsPath $AppsPath -ConfigState $CurrentConfig`
- Compare each component's file hashes with stored manifest
- For each component, compare file count and individual hashes
- Build $changedFiles array with entries like "Office\setup.exe (hash mismatch)" or "Defender: 3 new files"
- If $changedFiles.Count -gt 0: return `@{ Stale = $true; Reason = "Content files changed"; Action = "Rebuild"; Details = $changedFiles }`

**No changes detected:**
- return `@{ Stale = $false; Reason = "Apps.iso is current - no content or config changes detected"; Action = "Skip"; Details = @() }`

Add comprehensive logging with WriteLog:
- "Checking Apps.iso staleness..."
- "  Tier 1: ISO exists at {path}"
- "  Tier 2: Manifest found, comparing configuration..."
- "  Tier 2: Config mismatch: {key} changed from {old} to {new}"
- "  Tier 3: Comparing file hashes..."
- "  Tier 3: {component}: {count} files changed"
- "  Result: {Action} - {Reason}"

$currentConfig = @{
    InstallOffice = $InstallOffice
    UpdateLatestDefender = $UpdateLatestDefender
    UpdateLatestMSRT = $UpdateLatestMSRT
    UpdateEdge = $UpdateEdge
    UpdateOneDrive = $UpdateOneDrive

if ($stalenessResult.Stale) {
    WriteLog "APPS.ISO STALENESS: $($stalenessResult.Reason)"
    if ($stalenessResult.Details.Count -gt 0) {
        WriteLog "  Changed items:"
        foreach ($detail in $stalenessResult.Details) {
            WriteLog "    - $detail"
        }
    }
    WriteLog "  Action: $($stalenessResult.Action)"

    # Remove stale ISO to force rebuild
    if (Test-Path $AppsISO) {
        if (-not [string]::IsNullOrWhiteSpace($AppsISO)) {
            Remove-Item -Path $AppsISO -Force -ErrorAction SilentlyContinue
        }
        WriteLog "Stale Apps.iso removed. New ISO will be created."

} else {
    WriteLog "APPS.ISO CURRENT: $($stalenessResult.Reason)"
    WriteLog "  Action: Skip rebuild"
}
