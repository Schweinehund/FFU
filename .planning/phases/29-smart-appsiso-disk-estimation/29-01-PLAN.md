  <action>
Add `New-AppsContentManifest` function to FFU.Apps.psm1.

Function signature:
```powershell
function New-AppsContentManifest {
    [CmdletBinding()]
    [OutputType([hashtable])]
    param(
        [Parameter(Mandatory)]
        [string]$AppsPath,

        [Parameter(Mandatory)]
        [hashtable]$ConfigState
    )
}
```

Implementation requirements:
1. Create manifest structure with Version (1.0.0), Generated timestamp (UTC ISO 8601), ConfigState hashtable
2. Define component paths relative to AppsPath:
   - Orchestration: `$AppsPath\Orchestration`
   - Office: `$AppsPath\Office`
   - Defender: `$AppsPath\Defender`
   - MSRT: `$AppsPath\MSRT`
   - Edge: `$AppsPath\Edge`
   - OneDrive: `$AppsPath\OneDrive`
   - Win32: `$AppsPath\Win32`
   - MSStore: `$AppsPath\MSStore`
3. For each component that exists:
   - Get all files recursively with Get-ChildItem -Recurse -File
   - For each file, compute SHA256 hash using Get-FileHash -Algorithm SHA256
   - Store: relative path (from AppsPath), hash, size
   - Sum total size for component
4. Store config state keys: InstallOffice, UpdateLatestDefender, UpdateLatestMSRT, UpdateEdge, UpdateOneDrive
5. Calculate overall ManifestHash (SHA256 of the manifest JSON string, excluding ManifestHash field)
6. Write manifest to `$AppsPath\.manifest.json` using ConvertTo-Json -Depth 10
7. Return the manifest hashtable

Use WriteLog for progress logging:
- "Generating Apps content manifest..."
- "  Hashing {component}: {fileCount} files, {sizeGB} GB"
- "Manifest saved: {path}"

Error handling: Wrap in try/catch, log errors with WriteLog, re-throw.
  </action>
