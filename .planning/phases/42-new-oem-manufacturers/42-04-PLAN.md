Logic (follow Microsoft's Save-MicrosoftDriversTask flow closely):

1. Extract `$modelName`, `$modelLink`, `$make` from `$DriverItemData` (same as Microsoft pattern).
2. Set initial `$driverRelativePath`, `$status`, `$success = $false`.
3. Check for existing drivers via `Test-ExistingDriver` (identical to Microsoft pattern, including CompressToWim handling for existing folders).
4. **Navigate to model download page:**
   - Use `Invoke-WebRequest -Uri $modelLink -UseBasicParsing -Headers $Headers -UserAgent $UserAgent` to fetch the Samsung model download page.
   - Parse for ZIP download links. Samsung driver packs are ZIP files. Look for links ending in `.zip` that contain the model name or "driver" keyword:
     ```powershell
     $zipPattern = 'href="(https?://[^"]+\.zip)"'
     $zipMatches = [regex]::Matches($pageContent.Content, $zipPattern, [System.Text.RegularExpressions.RegexOptions]::IgnoreCase)
     ```
   - If multiple ZIPs found, prefer the one matching the Windows release (`Win11`, `Win10`, or `W11`, `W10` in filename).
   - If the `$modelLink` itself IS a direct ZIP URL (ends in `.zip`), skip page scraping and download directly.

5. **Download and extract:**
   - Create directory structure: `$DriversFolder/$make/$sanitizedModelName`
   - Use `ConvertTo-SafeName` for model name sanitization (same as Microsoft).
   - Download via `Start-BitsTransferWithRetry -Source $downloadLink -Destination $filePath`.
   - Extract: `Expand-Archive -Path $filePath -DestinationPath $modelPath -Force` (with `$ProgressPreference = 'SilentlyContinue'` to suppress progress bars).
   - Remove downloaded ZIP after extraction.

6. **Compress to WIM if requested** (identical to Microsoft pattern -- copy the CompressToWim block from Save-MicrosoftDriversTask).

7. **Progress updates and return object:** Use `Invoke-ProgressUpdate` for status updates throughout (same as Microsoft). Return `[PSCustomObject]@{ Model = $modelName; Status = $status; Success = $success; DriverPath = $driverRelativePath }`.

8. **Error handling:** Wrap in try/catch with the same error return pattern as Microsoft's Save-MicrosoftDriversTask.

**Function signature (follows Get-MicrosoftDrivers pattern):**
```powershell
function Get-SamsungDrivers {
    <#
    .SYNOPSIS
    Downloads and extracts Samsung Galaxy Book drivers for FFU builds

    .DESCRIPTION
    Downloads Samsung Galaxy Book driver packs from the Samsung enterprise portal
    or uses a static model list fallback. Driver packs are ZIP files extracted
    with Expand-Archive. Follows the Microsoft Surface pattern for HTML-based
    OEM driver acquisition.

    .PARAMETER Make
    OEM manufacturer name (expected: "Samsung")

    .PARAMETER Model
    Samsung model name (e.g., "Galaxy Book4 Pro")

    .PARAMETER WindowsRelease
    Windows release version (10 or 11)

    .PARAMETER Headers
    HTTP headers for web requests

    .PARAMETER UserAgent
    User agent string for web requests

    .PARAMETER DriversFolder
    Root path where drivers should be downloaded and extracted

    .PARAMETER FFUDevelopmentPath
    Root FFUDevelopment path for download tracking

    .EXAMPLE
    Get-SamsungDrivers -Make "Samsung" -Model "Galaxy Book4 Pro" -WindowsRelease 11 `
                       -Headers $Headers -UserAgent $UserAgent -DriversFolder "C:\FFU\Drivers" `
                       -FFUDevelopmentPath "C:\FFU"
    #>
    [CmdletBinding()]
    param (
        [Parameter(Mandatory = $true)]
        [string]$Make,

        [Parameter(Mandatory = $true)]
        [string]$Model,

        [Parameter(Mandatory = $true)]
        [ValidateSet(10, 11)]
        [int]$WindowsRelease,

        [Parameter(Mandatory = $true)]
        [hashtable]$Headers,

        [Parameter(Mandatory = $true)]
        [string]$UserAgent,

        [Parameter(Mandatory = $true)]
        [string]$DriversFolder,

        [Parameter(Mandatory = $true)]
        [string]$FFUDevelopmentPath
    )
```

**Logic (follows Get-MicrosoftDrivers flow):**

1. **Define static model list** (same as in FFUUI.Core module -- duplicate here for build-time independence). Include a `Link` property for each model pointing to the Samsung portal. This list is both the fallback and the lookup source.

2. **Attempt portal scraping** for the selected model's download page:
   - Use `[FFUConstants]::SAMSUNG_PORTAL_URL` as the base URL.
   - Try `Invoke-WebRequest` to fetch the portal page. Wrap in try/catch with WebException handling (same as Get-MicrosoftDrivers pattern).
   - Parse HTML for download links matching the model name and `.zip` extension.

3. **Model lookup fallback:**
   - If portal scraping fails or returns no download link for the selected model, search the static model list.
   - Log: `WriteLog "[Samsung][$Model][Selection] Portal scraping failed, using static model data"`
   - If model not found in static list either, log error and throw (same as Microsoft's "model not found" pattern).

4. **Download link resolution:**
   - If a direct ZIP download link was found from portal parsing, use it.
   - If using static list (portal URL only), attempt to construct or discover the download URL:
     - Try fetching the portal URL and scraping for download links matching the model.
     - If no download link can be resolved, log an actionable error:
       `WriteLog "[Samsung][$Model][Error] No downloadable driver pack found. Visit $([FFUConstants]::SAMSUNG_PORTAL_URL) to manually download drivers for $Model"`
     - Throw with a descriptive message so the build continues for other OEMs.

5. **Directory creation and download:**
   - Create `$DriversFolder/Samsung/<sanitizedModel>` folder structure.
   - Use `ConvertTo-SafeName` for model name sanitization.
   - Download via `Invoke-DriverDownloadWithRetry` (not BITS -- consistent with Get-MicrosoftDrivers).
   - Track downloads via `Set-DownloadInProgress` / `Clear-DownloadInProgress`.

6. **Extraction:**
   - Samsung driver packs are ZIP files. Use `Expand-Archive -Path $filePath -DestinationPath $modelPath -Force`.
   - Suppress progress: `$ProgressPreference = 'SilentlyContinue'` before extraction, restore after.
   - Log: `WriteLog "[Samsung][$Model][Extract] Extracting ZIP driver pack to $modelPath"`

7. **Cleanup:** Remove the downloaded ZIP file after successful extraction.

8. **Error handling:** Wrap entire function body in try/catch. On `[System.Net.WebException]`, log network-specific error with remediation. On general exception, log with context and re-throw. Use structured logging throughout:
   - `WriteLog "[Samsung][$Model][Download] Downloading driver pack from $downloadLink"`
   - `WriteLog "[Samsung][$Model][Extract] Extraction complete"`
   - `WriteLog "[Samsung][$Model][Error] Failed to download: $($_.Exception.Message)"`
