**Function 1: Get-AcerDriversModelList**

Signature:
```powershell
function Get-AcerDriversModelList {
    [CmdletBinding()]
    param (
        [Parameter(Mandatory = $true)]
        [string]$DriversFolder,
        [Parameter(Mandatory = $true)]
        [string]$Make  # Expected to be 'Acer'
    )
```

Logic:
1. Log: `WriteLog "Getting Acer driver model list..."`
2. Set up paths:
   - `$acerDriversFolder = Join-Path -Path $DriversFolder -ChildPath $Make`
   - `$catalogXmlPath = Join-Path -Path $acerDriversFolder -ChildPath "AcerCatalog.xml"`
3. Ensure `$acerDriversFolder` exists (create if not)
4. Download/cache the catalog XML using `Get-CachedOEMCatalog`:
   - `-Vendor 'Acer'` — NOTE: Get-CachedOEMCatalog has a ValidateSet on Vendor that currently only includes 'Dell', 'HP', 'Lenovo'. The 42-07 infrastructure plan MUST have already added 'Acer' to this ValidateSet before this plan executes. If for some reason it hasn't, use `Invoke-DriverDownloadWithRetry` directly as a fallback download method with 7-day cache check (same pattern as HP's Get-HPDriversModelList uses Start-BitsTransferWithRetry with manual cache age check).

   **Preferred path (if 42-07 updated ValidateSet):**
   ```powershell
   Get-CachedOEMCatalog -Vendor 'Acer' -CatalogType 'SCCM' -PrimaryUrl ([FFUConstants]::ACER_CATALOG_URL) -CachePath $catalogXmlPath
   ```

   **Fallback path (if ValidateSet not updated — implement this as the safe default):**
   ```powershell
   # Manual cache check + download (same as HP pattern in FFUUI.Core.Drivers.HP.psm1 lines 38-50)
   if (-not (Test-Path -Path $catalogXmlPath) -or ((Get-Date) - (Get-Item $catalogXmlPath).LastWriteTime).TotalDays -gt 7) {
       WriteLog "Downloading AcerCatalog.xml to $catalogXmlPath"
       Start-BitsTransferWithRetry -Source ([FFUConstants]::ACER_CATALOG_URL) -Destination $catalogXmlPath -ErrorAction Stop
       WriteLog "AcerCatalog.xml download complete."
   } else {
       WriteLog "Using existing AcerCatalog.xml found at $catalogXmlPath"
   }
   ```

   **IMPORTANT:** Since Acer's catalog is a direct XML file (not CAB-wrapped), there is NO expand.exe extraction step. The downloaded file IS the XML. This is the key difference from Dell/HP.

5. Parse the XML to extract model list. The exact XML schema needs to be validated at runtime by fetching the actual catalog. The RESEARCH.md provides an expected schema:
   ```xml
   <AcerCatalog>
     <ModelList>
       <Model name="Aspire 5 A515-56">
         <SCCM os="Windows 11" version="23H2">https://...</SCCM>
       </Model>
     </ModelList>
   </AcerCatalog>
   ```

   However, the actual XML schema may differ. Implement a **defensive parser** that:
   - Loads the XML: `[xml]$catalogContent = Get-Content -Path $catalogXmlPath -Raw -Encoding UTF8 -ErrorAction Stop`
   - Tries the expected schema first: look for `ModelList/Model` nodes with `name` attribute
   - If that yields 0 results, try alternate approaches:
     - Look for any element with a `name` or `Name` attribute that could be a model
     - Try `//Model` XPath at any nesting depth
     - Log what root element and child elements exist to help debug schema mismatches
   - For each model found, create: `[PSCustomObject]@{ Make = $Make; Model = $modelName }`
   - Use a HashSet for deduplication (same as HP pattern)
   - Add to a `[System.Collections.Generic.List[PSCustomObject]]`

6. Log: `WriteLog "Successfully parsed $($modelList.Count) unique Acer models from AcerCatalog.xml."`
7. Wrap entire function body in try/catch. Catch logs: `WriteLog "Error getting Acer driver model list: $($_.Exception.Message)"`
8. Return `$modelList | Sort-Object -Property Model`

**Function 2: Save-AcerDriversTask**

Follow the HP Save-HPDriversTask pattern exactly for the function signature and return contract. This function is called by the parallel driver download orchestrator.

Signature:
```powershell
function Save-AcerDriversTask {
    [CmdletBinding()]
    param (
        [Parameter(Mandatory = $true)]
        [PSCustomObject]$DriverItemData,  # Contains Make, Model
        [Parameter(Mandatory = $true)]
        [string]$DriversFolder,
        [Parameter(Mandatory = $true)]
        [ValidateSet("x64", "x86", "ARM64")]
        [string]$WindowsArch,
        [Parameter(Mandatory = $true)]
        [ValidateSet(10, 11)]
        [int]$WindowsRelease,
        [Parameter(Mandatory = $true)]
        [string]$WindowsVersion,  # e.g., 22H2, 23H2
        [Parameter()]
        [System.Collections.Concurrent.ConcurrentQueue[hashtable]]$ProgressQueue = $null,
        [Parameter()]
        [bool]$CompressToWim = $false,
        [Parameter()]
        [bool]$PreserveSourceOnCompress = $false
    )
```

Logic:
1. Extract `$modelName = $DriverItemData.Model`, `$make = $DriverItemData.Make`, set `$identifier = $modelName`
2. Sanitize model name: `$sanitizedModelName = ConvertTo-SafeName -Name $modelName`
3. Set up paths: `$acerDriversBaseFolder`, `$modelSpecificFolder`, `$driverRelativePath` (same pattern as HP)
4. Check existing drivers via `Test-ExistingDriver` (identical to HP lines 143-173, including compression handling for existing folders)
5. If not existing, proceed:
   a. Ensure AcerCatalog.xml is available (re-download if needed, same guard as HP lines 180-194 but for Acer catalog)
   b. Parse catalog XML to find the selected model's driver package URL:
      - Load XML: `[xml]$catalogContent = Get-Content -Path $catalogXmlPath -Raw -Encoding UTF8`
      - Find model node matching `$modelName`
      - Find SCCM child element matching requested OS: look for `os` attribute containing "Windows $WindowsRelease" and `version` attribute matching `$WindowsVersion`
      - If exact version not found, fall back to newest available version for the same OS release (same fallback logic principle as HP's version fallback)
      - Extract the driver package download URL from the matching SCCM element's text content
   c. If no driver URL found, throw: `"No driver pack found for Acer model '$modelName' matching Windows $WindowsRelease $WindowsVersion"`
   d. Download driver package:
      - Determine file extension from URL (.cab or .zip)
      - `$driverPackFile = Join-Path -Path $acerDriversBaseFolder -ChildPath "AcerDriverPack_$($sanitizedModelName)$extension"`
      - `Start-BitsTransferWithRetry -Source $driverPackUrl -Destination $driverPackFile -ErrorAction Stop`
   e. Extract driver package:
      - If `.cab`: `Invoke-Process -FilePath "expand.exe" -ArgumentList @($driverPackFile, "-F:*", $modelSpecificFolder) -ErrorAction Stop | Out-Null`
      - If `.zip`: `Expand-Archive -Path $driverPackFile -DestinationPath $modelSpecificFolder -Force -ErrorAction Stop`
      - Note: For CAB extraction to a folder, expand.exe syntax is: `expand.exe <source.cab> -F:* <destination_folder>`. Ensure the destination folder exists first.
   f. Cleanup: Remove `$driverPackFile` after extraction
   g. WIM compression if `$CompressToWim` (identical to HP lines 401-415)
6. Return `[PSCustomObject]@{ Identifier = $identifier; Status = $finalStatus; Success = $successState; DriverPath = $driverRelativePath }` — identical return contract to HP

```powershell
function Get-AcerDrivers {
    <#
    .SYNOPSIS
    Downloads and extracts Acer drivers for FFU builds

    .DESCRIPTION
    Downloads Acer SCCM driver catalog (AcerCatalog.xml), parses available models,
    and extracts the appropriate driver package for the specified Acer model and
    Windows version. Uses Acer's online XML catalog for driver discovery.

    .PARAMETER Make
    OEM manufacturer name (should be "Acer")

    .PARAMETER Model
    Acer model name (e.g., "Aspire 5 A515-56", "TravelMate P2 TMP214-54")

    .PARAMETER WindowsArch
    Windows architecture (x64, x86, or ARM64)

    .PARAMETER WindowsRelease
    Windows release version (10 or 11)

    .PARAMETER DriversFolder
    Root path where drivers should be downloaded and extracted

    .PARAMETER FFUDevelopmentPath
    Root FFUDevelopment path for download tracking

    .PARAMETER isServer
    Boolean indicating if target OS is Windows Server (Acer does not support Server — logs warning and returns)

    .EXAMPLE
    Get-AcerDrivers -Make "Acer" -Model "Aspire 5 A515-56" -WindowsArch "x64" `
                    -WindowsRelease 11 -DriversFolder "C:\FFU\Drivers" `
                    -FFUDevelopmentPath "C:\FFU" -isServer $false
    #>
    [CmdletBinding()]
    param (
        [Parameter(Mandatory = $true)]
        [string]$Make,

        [Parameter(Mandatory = $true)]
        [string]$Model,

        [Parameter(Mandatory = $true)]
        [ValidateSet("x64", "x86", "ARM64")]
        [string]$WindowsArch,

        [Parameter(Mandatory = $true)]
        [int]$WindowsRelease,

        [Parameter(Mandatory = $true)]
        [string]$DriversFolder,

        [Parameter(Mandatory = $true)]
        [string]$FFUDevelopmentPath,

        [Parameter(Mandatory = $true)]
        [bool]$isServer
    )
```

**Logic (follow Get-DellDrivers structure):**

1. Server guard:
   ```powershell
   if ($isServer) {
       WriteLog "WARNING: [Acer][$Model][Catalog] Acer does not provide Windows Server driver catalogs. Skipping Acer driver download."
       return
   }
   ```

2. Create OEM drivers folder:
   ```powershell
   if (-not (Test-Path -Path $DriversFolder)) {
       WriteLog "Creating Drivers folder: $DriversFolder"
       New-Item -Path $DriversFolder -ItemType Directory -Force | Out-Null
   }
   $DriversFolder = "$DriversFolder\$Make"
   WriteLog "[Acer][$Model][Setup] Creating Acer Drivers folder: $DriversFolder"
   New-Item -Path $DriversFolder -ItemType Directory -Force | Out-Null
   ```

3. Disk space validation (same as Dell):
   ```powershell
   $spaceCheck = Test-DriverDiskSpace -DriversFolder $DriversFolder -Vendor 'Acer' -EstimatedCompressedSizeMB 500
   if (-not $spaceCheck.HasSpace) {
       WriteLog "WARNING: [Acer][$Model][DiskSpace] $($spaceCheck.Message)"
       WriteLog "WARNING: [Acer][$Model][DiskSpace] $($spaceCheck.Recommendation)"
   } else {
       WriteLog $spaceCheck.Message
   }
   ```
   Note: Acer driver packs are typically smaller than Dell (est. 500MB compressed vs Dell's 2500MB).

4. Download and cache catalog XML:
   ```powershell
   $catalogXmlPath = Join-Path -Path $DriversFolder -ChildPath "AcerCatalog.xml"
   ```
   Use the same download approach as Task 1's Get-AcerDriversModelList — either Get-CachedOEMCatalog (if 42-07 added 'Acer' to ValidateSet) or manual cache check with Start-BitsTransferWithRetry. Since this is the build-time function and Get-CachedOEMCatalog's ValidateSet includes 'Acer' (added by 42-07 infrastructure plan which is a dependency), prefer Get-CachedOEMCatalog:
   ```powershell
   WriteLog "[Acer][$Model][Catalog] Downloading Acer catalog..."

       -PrimaryUrl ([FFUConstants]::ACER_CATALOG_URL) -CachePath $catalogXmlPath
   ```
   If Get-CachedOEMCatalog's ValidateSet has NOT been updated (verify by checking the function's param block), fall back to the manual download pattern.

5. Parse catalog XML to find model and driver URL:
   ```powershell
   WriteLog "[Acer][$Model][Catalog] Parsing AcerCatalog.xml for model '$Model'..."
   [xml]$catalogContent = Get-Content -Path $catalogXmlPath -Raw -Encoding UTF8 -ErrorAction Stop
   ```
   - Find model node matching `$Model` (defensive: try multiple XPath approaches)
   - Find SCCM element matching Windows release
   - Extract driver package URL

6. Download driver package:
   - Determine file type from URL (CAB vs ZIP)
   - Use `Invoke-DriverDownloadWithRetry` for the download (this is the build-time path, use the retry-capable function)
   - Log: `WriteLog "[Acer][$Model][Download] Downloading driver pack from $driverPackUrl"`

7. Extract driver package:
   - CAB: `Invoke-Process -FilePath "expand.exe" -ArgumentList @(...)`
   - ZIP: `Expand-Archive -Path ... -DestinationPath ... -Force`
   - Log: `WriteLog "[Acer][$Model][Extract] Extracting driver pack to $DriversFolder"`

8. Cleanup: Remove downloaded archive after extraction

9. Error handling: Wrap entire function body in try/catch. On catch:
   ```powershell
   WriteLog "ERROR: [Acer][$Model][Failed] $($_.Exception.Message)"
   WriteLog "ERROR: [Acer][$Model][Remediation] Check network connectivity and verify the Acer catalog URL is accessible: $([FFUConstants]::ACER_CATALOG_URL)"
   ```
   Do NOT re-throw — follow the graceful degradation pattern (build continues without Acer drivers).
