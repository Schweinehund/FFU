**Exception type mapping:**
- Parameter validation: [System.ArgumentException], [System.ArgumentNullException]
- File operations: [System.IO.IOException], [System.IO.FileNotFoundException]
- CIM/WMI queries: [Microsoft.Management.Infrastructure.CimException]
- Configuration: [System.InvalidOperationException]
- Network: [System.Net.WebException]

**Pattern to follow:**
```powershell
try {
    # operation
}
catch [System.IO.IOException] {
    $errorContext = "Failed to [operation] for [resource]: $($_.Exception.Message)"
    if ($function:WriteLog) { WriteLog "ERROR: $errorContext" }
    throw [System.IO.IOException]::new($errorContext, $_.Exception)
}
catch {
    $errorContext = "Unexpected error in [function]: $($_.Exception.Message)"
    if ($function:WriteLog) { WriteLog "ERROR: $errorContext" }
    throw
}
```

Preserve existing behavior - only enhance error context, do not change function logic.
