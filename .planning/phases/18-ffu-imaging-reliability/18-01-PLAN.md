  <action>
    Create Test-DiskSpaceForOperation function in FFU.Imaging.psm1. Follow the pattern from Test-CheckpointDiskSpace in FFU.VM:

    **Function signature:**
    ```powershell
    function Test-DiskSpaceForOperation {
        [CmdletBinding()]
        [OutputType([PSCustomObject])]
        param(
            [Parameter(Mandatory)]
            [string]$Path,

            [Parameter(Mandatory)]
            [int64]$RequiredBytes,

            [Parameter()]
            [int]$SafetyMarginPercent = 10,

            [Parameter()]
            [string]$OperationName = 'imaging operation'
        )
    }
    ```

    **Implementation:**
    1. Use System.IO.DriveInfo to get available space (works without Storage module)
    2. Calculate required space with safety margin: `$requiredWithMargin = $RequiredBytes * (1 + $SafetyMarginPercent / 100)`
    3. Return structured object:
       - HasSufficientSpace: bool
       - Drive: string (e.g., "C:\")
       - AvailableBytes: int64
       - AvailableGB: decimal (rounded 2 places)
       - RequiredBytes: int64 (with margin)
       - RequiredGB: decimal (rounded 2 places)
       - ShortfallBytes: int64 (0 if sufficient)
       - ShortfallGB: decimal (0 if sufficient)
       - Message: string (human readable)
       - Remediation: string (actionable guidance when insufficient)

    **Remediation message format:**
    "Free up {ShortfallGB} GB on {Drive} or move the operation to a drive with more space."

    **Export function** in FFU.Imaging.psd1 FunctionsToExport array.

    **Note:** Use [System.IO.Path]::GetPathRoot($Path) to extract drive, not Split-Path -Qualifier (works better with UNC paths).
  </action>

    Import FFU.Imaging module and verify function is exported:

