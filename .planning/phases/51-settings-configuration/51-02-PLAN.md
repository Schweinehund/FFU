**BuildConfigurationTests.cs** — Create test class covering serialization compatibility:

1. `Defaults_MatchSchemaDefaults` — verify `new BuildConfiguration()` has the same default values as the schema (Memory=4294967296, Disksize=32212254720, Processors=4, WindowsSKU="Pro", etc.)

2. `Serialize_ProducesCompatibleJson` — serialize a BuildConfiguration and verify the JSON contains the exact key names the PowerShell UI expects (e.g., "Memory", "Disksize", "WindowsRelease", "InstallApps"). Use `JsonConvert.SerializeObject` and check for key presence.

3. `Deserialize_PowerShellConfigJson` — create a JSON string matching the Sample_default.json format and deserialize it. Verify all properties are populated correctly. This is the critical round-trip test.

4. `Deserialize_HandlesExtraProperties` — deserialize JSON with unknown properties (future schema additions). Should not throw. Verify via `[JsonExtensionData]` on AdditionalData.

5. `Deserialize_HandlesMissingProperties` — deserialize JSON with only a few properties. Should use defaults for missing ones.

6. `MemoryAndDisksize_StoredAsBytes` — verify that Memory=4294967296 (4GB in bytes) and Disksize=32212254720 (30GB in bytes) in serialized JSON.

7. `WindowsRelease_IsInteger` — verify WindowsRelease serializes as integer 11, not string "11".

**SettingsViewModelTests.cs** — Create test class with mocked IConfigurationService:

1. `Constructor_InitializesWithDefaults` — new SettingsViewModel has non-null Configuration, IsDirty is false.

2. `ResetToDefaults_SetsDefaultConfiguration` — call ResetToDefaultsCommand, verify Configuration has default values.

3. `ResetToDefaults_SetsIsDirty` — after reset, IsDirty should be true (user needs to save).

4. `LoadConfig_ClearsIsDirty` — mock configService.LoadAsync to return a config, call LoadConfigCommand, verify IsDirty is false.

5. `SaveConfig_ClearsIsDirty` — set IsDirty to true, call SaveConfigCommand (mock the save), verify IsDirty becomes false.

6. `MemoryGB_ConvertsCorrectly` — set MemoryGB = 4.0, verify Configuration.Memory == 4294967296. Set Configuration.Memory = 8589934592, verify MemoryGB == 8.0.

7. `DisksizeGB_ConvertsCorrectly` — set DisksizeGB = 30.0, verify Configuration.Disksize == 32212254720. Set Configuration.Disksize = 53687091200, verify DisksizeGB == 50.0.

8. `Validation_MemoryOutOfRange_HasError` — set MemoryGB to 1 (below 2GB minimum), call ValidateAll, verify HasErrors is true and GetErrors("MemoryGB") returns error.

9. `Validation_ProcessorsOutOfRange_HasError` — set Processors to 0 or 65, verify validation error.

10. `Validation_ValidConfig_NoErrors` — use default config, validate, verify HasErrors is false.

11. `EnumOptions_ContainExpectedValues` — verify WindowsSKUOptions contains "Pro", "Enterprise", "Home", etc. Verify MakeOptions contains "Dell", "HP", "Lenovo".
