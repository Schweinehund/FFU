Create new module FFUUI.Core.JobErrors.psm1 with job error extraction functions:

**1. Get-FFUJobError** - Main function to extract error from job
```powershell
function Get-FFUJobError {
    [CmdletBinding()]
    [OutputType([PSCustomObject])]
    param(
        [Parameter(Mandatory)]
        [System.Management.Automation.Job]$Job,

        [Parameter()]
        [hashtable]$MessagingContext,  # Synchronized messaging context from FFU.Messaging

        [Parameter()]
        [string]$LogPath
    )
}
```

Implementation logic (in priority order):
1. **Check MessagingContext first** - Most reliable source of structured errors
   - If MessagingContext provided, drain queue looking for Error/Critical level messages
   - Use Read-FFUMessage to get remaining messages (don't consume, peek)
   - Look for messages where Level -ge [FFUMessageLevel]::Error
   - Extract: Message, Source, Data (may contain remediation, details)

2. **Check Job.ChildJobs for errors** (ThreadJob pattern)
   - If Job has ChildJobs, check their Error streams
   - Extract error message and exception details

3. **Check Job.JobStateInfo.Reason**
   - Standard PowerShell job failure reason
   - Often contains exception message

4. **Check Job output for error patterns**
   - Search output for lines matching: error|exception|failed|fatal
   - Use as fallback context

5. **Fallback to generic message**
   - If all above fail, return structured error with generic message
   - Include log path hint if available

Return structure:
```powershell
[PSCustomObject]@{
    ErrorType = 'BuildError'  # DISMError, HypervisorError, NetworkError, Unknown
    Title = 'Build Failed: [specific issue]'
    Message = 'Detailed error description'
    Source = 'FFU.Imaging'  # Module that raised the error
    Remediation = @('Step 1', 'Step 2')  # May be empty
    Details = @{  # May be empty
        ExitCode = 1234
        Command = 'DISM /Apply-Image'
    }
    LogPath = $LogPath
    OriginalException = $null  # Exception object if available
}
```

**2. ConvertTo-FFUErrorInfo** - Convert FFUMessage to error info structure
```powershell
function ConvertTo-FFUErrorInfo {
    [CmdletBinding()]
    [OutputType([PSCustomObject])]
    param(
        [Parameter(Mandatory)]
        [PSCustomObject]$FFUMessage  # FFUMessage object from queue
    )
}
```

Extract from FFUMessage:
- Message -> Title (truncate if too long)
- Message -> Message (full text)
- Source -> Source
- Data['Remediation'] -> Remediation (if present)
- Data['ErrorType'] -> ErrorType (if present, else 'BuildError')
- Data -> Details (minus Remediation/ErrorType)

**3. Get-ErrorTypeFromMessage** - Classify error type from message text
```powershell
function Get-ErrorTypeFromMessage {
    [CmdletBinding()]
    [OutputType([string])]
    param([string]$Message)
}
```

Pattern matching to classify:
- 'DISM|Mount|WIM|image' -> 'DISMError'
- 'Hyper-V|VM|Virtual' -> 'HypervisorError'
- 'network|connection|share|SMB' -> 'NetworkError'
- 'disk|space|storage' -> 'DiskError'
- 'permission|access denied|0x80070005' -> 'PermissionError'
- default -> 'BuildError'
