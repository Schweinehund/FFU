Create new module FFUUI.Core.ErrorDisplay.psm1 with structured error display functions:

**1. Show-FFUError** - Main error display function
```powershell
function Show-FFUError {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]
        [ValidateSet('Critical', 'Error', 'Warning', 'Info')]
        [string]$Severity,

        [Parameter(Mandatory)]
        [string]$Title,

        [Parameter(Mandatory)]
        [string]$Description,

        [Parameter()]
        [string[]]$Remediation,  # Array of steps to fix

        [Parameter()]
        [string]$LogPath,  # If exists, add "Open Log" button

        [Parameter()]
        [System.Management.Automation.ErrorRecord]$ErrorRecord,  # For Details

        [Parameter()]
        [hashtable]$Details  # Additional key-value pairs to show
    )
}
```

Implementation:
- Build message with sections: [SEVERITY], Description, === WHAT TO DO ===, [log path if exists]
- Use appropriate MessageBox icon based on severity (Error, Warning, Information)
- For Critical/Error: use MessageBoxButton.OK with Error icon
- Include "Check log file: [path]" line when LogPath provided and file exists
- Format remediation as numbered list if multiple steps
- If ErrorRecord provided, append technical details (Exception.Message, ScriptStackTrace)
- Return MessageBoxResult for caller if needed

**2. Show-FFUValidationErrors** - Validation-specific error display
```powershell
function Show-FFUValidationErrors {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]
        [string[]]$Errors,

        [Parameter()]
        [string[]]$Warnings,

        [Parameter()]
        [string]$Title = "Configuration Validation Failed",

        [Parameter()]
        [string]$ConfigPath
    )
}
```

Implementation:
- Build message with "The following errors were found:" header
- List errors as bullet points with "(X)" prefix
- List warnings as bullet points with "(!)" prefix
- Add "Config file: [path]" if ConfigPath provided
- Use Error icon if Errors present, Warning icon if only Warnings

**3. Format-FFUErrorMessage** - Internal helper to format error text
```powershell
function Format-FFUErrorMessage {
    [CmdletBinding()]
    [OutputType([string])]
    param(
        [string]$Title,
        [string]$Description,
        [string[]]$Remediation,
        [string]$LogPath,
        [hashtable]$Details
    )
}
```

Use WriteLog for all error display calls (for debugging).
Do NOT use emojis - use text markers like [ERROR], [WARNING], ===, ---.
