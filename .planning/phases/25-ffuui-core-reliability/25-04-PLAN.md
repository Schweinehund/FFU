<objective>
Add load-time configuration validation to catch invalid settings before build starts.

Purpose: Currently validation only runs in BuildFFUVM.ps1 when the user clicks Build, meaning
users can spend time configuring options only to discover their config is invalid at build time.
This plan integrates Test-FFUConfiguration (from FFU.Core) into the config loading workflow,
showing validation errors immediately when a config file is loaded.

Output: Modified Invoke-LoadConfiguration that validates config before applying to UI,
with validation errors shown via Show-FFUValidationErrors (from Plan 02).
</objective>

After parsing JSON (around line 336-348), add validation:
```powershell
# After: $configContent = $raw | ConvertFrom-Json -ErrorAction Stop

# Validate configuration against schema
$validationResult = $null
try {
    # Convert PSCustomObject to hashtable for Test-FFUConfiguration
    $configHashtable = @{}
    foreach ($prop in $configContent.PSObject.Properties) {
        $configHashtable[$prop.Name] = $prop.Value
    }
    $validationResult = Test-FFUConfiguration -ConfigObject $configHashtable
}
catch {
    WriteLog "LoadConfig: Validation check failed: $($_.Exception.Message)"
    # Continue without validation if Test-FFUConfiguration unavailable
}

if ($null -ne $validationResult -and -not $validationResult.IsValid) {
    WriteLog "LoadConfig: Validation found $($validationResult.Errors.Count) errors, $($validationResult.Warnings.Count) warnings"

    # Show validation errors to user
    Show-FFUValidationErrors `
        -Errors $validationResult.Errors `
        -Warnings $validationResult.Warnings `
        -Title "Configuration File Has Issues" `
        -ConfigPath $filePath

    # Ask user if they want to load anyway (with warnings)
    if ($validationResult.Errors.Count -gt 0) {
        $userChoice = [System.Windows.MessageBox]::Show(
            "The configuration file has validation errors.`n`nDo you want to load it anyway?`n(Some settings may not work correctly)",
            "Load Invalid Configuration?",
            [System.Windows.MessageBoxButton]::YesNo,
            [System.Windows.MessageBoxImage]::Warning
        )
        if ($userChoice -ne [System.Windows.MessageBoxResult]::Yes) {
            WriteLog "LoadConfig: User declined to load invalid configuration."
            return
        }
        WriteLog "LoadConfig: User chose to load configuration despite validation errors."
    }
}
elseif ($null -ne $validationResult -and $validationResult.Warnings.Count -gt 0) {
    # Show warnings but don't block
    WriteLog "LoadConfig: Validation passed with $($validationResult.Warnings.Count) warnings"
    # Could show brief warning toast/status, but don't interrupt
}

# Continue with existing Update-UIFromConfig call
Update-UIFromConfig -ConfigContent $configContent -State $State
```
