**4. Format-CheckDuration function** (internal helper, NOT exported):
```powershell
function Format-CheckDuration {
    [CmdletBinding()]
    [OutputType([string])]
    param(
        [Parameter()]
        [int]$DurationMs = 0
    )
    if ($DurationMs -le 0) { return '' }
    $seconds = [Math]::Round($DurationMs / 1000.0, 1)
    return " (${seconds}s)"
}
```
