<objective>
Add mutex-based file locking to all WinGetWin32Apps.json write operations to prevent JSON corruption during parallel Winget app downloads.

Purpose: BUGFIX-01 — When multiple parallel Winget app downloads complete simultaneously, each calls Add-Win32SilentInstallCommand which performs an unprotected read-modify-write on WinGetWin32Apps.json. This causes data loss (last writer wins) and potential JSON corruption (partial writes). The Get-Apps function also writes to the same file without protection when applying AppList.json overrides.

Output: FFU.Common.Winget.psm1 with mutex-protected JSON writes in both Add-Win32SilentInstallCommand and Get-Apps functions, following the existing mutex pattern from FFUUI.Core.Winget.psm1.
</objective>
