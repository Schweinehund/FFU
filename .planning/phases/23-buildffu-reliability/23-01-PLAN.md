  <name>Task 1: Implement error aggregation functions in FFU.Core</name>
  <files>FFUDevelopment/Modules/FFU.Core/FFU.Core.psm1</files>
  <action>
Add four new functions to FFU.Core.psm1 for build error aggregation:

1. **Script-scope collector variable** (add near top of module, after using statements):
```powershell
$script:BuildErrorCollector = [System.Collections.Generic.List[PSCustomObject]]::new()
```

2. **Add-BuildError function**:
- Parameters: Phase (string), Message (string), Severity (ValidateSet 'Critical','Warning','Info', default 'Warning'), Exception (optional System.Exception)
- Creates PSCustomObject with: Timestamp ([DateTime]::Now), Phase, Message, Severity, Exception
- Adds to $script:BuildErrorCollector
- Uses ThreadJob-safe logging pattern: `if ($function:WriteLog) { WriteLog "[$Severity] $Phase: $Message" }`
- Include [CmdletBinding()], [OutputType([void])], proper help

3. **Get-BuildErrorSummary function**:
- No parameters
- Returns PSCustomObject with: TotalCount, CriticalCount, WarningCount, InfoCount, Errors (array), HasCritical (bool)
- Uses Where-Object to count by severity
- Include [CmdletBinding()], [OutputType([PSCustomObject])], proper help

4. **Clear-BuildErrors function**:
- No parameters
- Clears $script:BuildErrorCollector (.Clear() method)
- Include [CmdletBinding()], [OutputType([void])], proper help

5. **Write-BuildErrorSummary function**:
- Parameter: Summary (PSCustomObject, mandatory)
- Writes formatted summary to log using WriteLog
- Format: Header with counts, then each error with severity prefix ([CRITICAL], [WARNING], [INFO])
- Uses ThreadJob-safe logging pattern
- Include [CmdletBinding()], [OutputType([void])], proper help

Add all four functions to the Export-ModuleMember -Function list.

  <action>
Create comprehensive Pester 5.x tests for the error aggregation functions:

```powershell
#Requires -Modules @{ ModuleName = 'Pester'; ModuleVersion = '5.0.0' }

Describe 'FFU.Core Build Error Aggregation' -Tag 'Unit', 'FFU.Core', 'REL-BUILD-04' {
    BeforeAll {
        # Import module
        $modulePath = Join-Path $PSScriptRoot '..\..\FFUDevelopment\Modules\FFU.Core'
        Import-Module $modulePath -Force
    }

    AfterEach {
        # Clean up errors between tests
        Clear-BuildErrors
    }

    Context 'Add-BuildError' {
        It 'Should add error with all properties' { ... }
        It 'Should default Severity to Warning' { ... }
        It 'Should accept Critical severity' { ... }
        It 'Should accept Info severity' { ... }
        It 'Should include Exception when provided' { ... }
        It 'Should set Timestamp to current time' { ... }
        It 'Should accumulate multiple errors' { ... }
    }

    Context 'Get-BuildErrorSummary' {
        It 'Should return empty summary when no errors' { ... }
        It 'Should count Critical errors correctly' { ... }
        It 'Should count Warning errors correctly' { ... }
        It 'Should count Info errors correctly' { ... }
        It 'Should set HasCritical to true when Critical errors exist' { ... }
        It 'Should set HasCritical to false when no Critical errors' { ... }
        It 'Should return all errors in Errors property' { ... }
    }

    Context 'Clear-BuildErrors' {
        It 'Should clear all accumulated errors' { ... }
        It 'Should be safe to call when empty' { ... }
    }

    Context 'Write-BuildErrorSummary' {
        It 'Should not throw on valid summary' { ... }
        It 'Should format Critical errors with [CRITICAL] prefix' { ... }
        It 'Should format Warning errors with [WARNING] prefix' { ... }
    }

    Context 'Integration Scenarios' {
        It 'Should handle mixed severity errors from multiple phases' {
            Add-BuildError -Phase 'DriverDownload' -Message 'Dell driver unavailable' -Severity Warning
            Add-BuildError -Phase 'UpdatesDownload' -Message 'KB5001234 failed' -Severity Critical
            Add-BuildError -Phase 'DriverDownload' -Message 'HP driver timeout' -Severity Warning
            Add-BuildError -Phase 'VMSetup' -Message 'TPM not available' -Severity Info

            $summary = Get-BuildErrorSummary
            $summary.TotalCount | Should -Be 4
            $summary.CriticalCount | Should -Be 1
            $summary.WarningCount | Should -Be 2
            $summary.InfoCount | Should -Be 1
            $summary.HasCritical | Should -Be $true
        }
    }
}
```

Include at least 15 test cases covering all functions and edge cases.
