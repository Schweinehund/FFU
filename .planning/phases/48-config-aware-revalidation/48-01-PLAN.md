**1. Export-DashboardDiagnostics**

Parameters: `[PSCustomObject]$State`

Generates a timestamped plain text diagnostics file for support scenarios. Uses `[System.Text.StringBuilder]` for efficient string building.

Implementation:
- Generate filename: `FFU-Diagnostics-$(Get-Date -Format 'yyyy-MM-dd-HHmmss').txt`
- Output path: `Join-Path $State.FFUDevelopmentPath 'Logs'` — create directory if it does not exist via `New-Item -ItemType Directory -Force`
- File structure (sections in this order):

  **Header:**
  ```
  ================================================================================
  FFU BUILDER PRE-FLIGHT DIAGNOSTICS REPORT
  ================================================================================
  Generated: {yyyy-MM-dd HH:mm:ss}
  ```

  **System Information:**
  ```
  SYSTEM INFORMATION
  --------------------------------------------------------------------------------
  OS Version       : {[Environment]::OSVersion.VersionString}
  PowerShell       : PowerShell {$PSVersionTable.PSVersion} ({$PSVersionTable.PSEdition})
  FFU Builder      : v{$State.Version.Number} (Build: {$State.Version.BuildDate})
  Hypervisor       : {Hyper-V | VMware Workstation Pro | Auto-detect based on cmbHypervisorType.SelectedIndex}
  Available Space  : {free GB on drive containing FFUDevelopmentPath} GB ({drive letter})
  ```

  Use `$State.Controls.cmbHypervisorType.SelectedIndex` to determine hypervisor name (0=Hyper-V, 1=VMware Workstation Pro, 2=Auto-detect). If Controls or cmbHypervisorType is null, use "Unknown".

  Use `[System.IO.DriveInfo]::new([System.IO.Path]::GetPathRoot($State.FFUDevelopmentPath))` for disk space. Wrap in try/catch — if disk info fails, output "Unable to determine".

  **Module Versions** (only if `$State.Version.Modules` exists):
  ```
  MODULE VERSIONS
  --------------------------------------------------------------------------------
    FFU.Common                    : v0.0.13
    FFUUI.Core                    : v0.2.0
    ...
  ```
  Iterate `$State.Version.Modules.PSObject.Properties` — pad name to 30 chars with `.PadRight(30)`.

  **Check Results** — iterate all 5 categories (System, Hypervisor, BuildTools, Network, Optimization):
  ```
  CHECK RESULTS
  --------------------------------------------------------------------------------

  [System]
    Total: 4 | Passed: 3 | Failed: 1 | Warning: 0

  [Hypervisor]
    Total: 3 | Passed: 3 | Failed: 0 | Warning: 0
  ```
  Read from `$State.Data.dashboardCategoryStats[$category]`. Skip categories with Total=0 or null stats.

  Also include individual check details if `$State.Data.dashboardCheckResults` exists (a hashtable keyed by check name with Status/Message/Severity/DurationMs). If this data store doesn't exist, just output category-level summaries. The data store will be populated by Plan 03 during UI wiring.

  For individual check detail output format:
  ```
    [PASS] Administrator - Running as administrator (0.1s)
    [FAIL] WimMount - WIMMount service not running (0.3s)
           Severity: Critical
           Remediation: Run sc.exe start WimMount...
  ```

  **Footer:**
  ```
  ================================================================================
  END OF REPORT
  ================================================================================
  ```

- Write file with `$sb.ToString() | Out-File -FilePath $outputPath -Encoding UTF8`
- Return the output file path as a string (the caller will show the MessageBox confirmation — separation of concerns for testability)

Add proper comment-based help: .SYNOPSIS, .DESCRIPTION, .PARAMETER State, .OUTPUTS [string], .EXAMPLE.

**2. Get-HypervisorDependentChecks**

Parameters: none

Returns a `[hashtable]` with three keys identifying which checks are dependent on hypervisor selection:
- `HyperV` = `@('HyperV')` — checks that ONLY run when HypervisorType = 'HyperV'
- `VMware` = `@('VmxToolkit', 'VMwareDrivers', 'HyperVSwitchConflict', 'VMwareBridgeConfig', 'HostIPAddress')` — checks that ONLY run when HypervisorType = 'VMware'
- `Independent` = `@('Administrator', 'PowerShellVersion', 'VMResources', 'ScratchSpace', 'ADK', 'WimMount', 'DiskSpace', 'DISMState', 'DISMCleanup', 'Network', 'Configuration', 'AntivirusExclusions', 'AppsISODiskSpace', 'CaptureDiskSpace')` — checks that run regardless of hypervisor

This mapping is derived from `Invoke-FFUPreflight` conditional execution logic in FFU.Preflight.psm1.

Add proper comment-based help with .SYNOPSIS, .DESCRIPTION, .OUTPUTS [hashtable].

**3. Set-CategoryDimmed**

Parameters: `[PSCustomObject]$State`, `[string]$Category`, `[bool]$IsDimmed`

Applies or removes visual dimming on a dashboard category expander:
- Get expander: `$State.Controls."exp$Category"` — return early if null
- If `$IsDimmed`:
  - Set `$expander.Opacity = 0.5`
  - Set `$State.Controls."txt${Category}Summary".FontStyle = [System.Windows.FontStyles]::Italic`
  - Set `$State.Controls."txt${Category}Summary".Text = '(rechecking...)'`
- If NOT `$IsDimmed`:
  - Set `$expander.Opacity = 1.0`
  - Set `$State.Controls."txt${Category}Summary".FontStyle = [System.Windows.FontStyles]::Normal`
  - (Do NOT change summary text — that will be updated by Update-CategorySummary when checks complete)

Add proper comment-based help.
