<objective>
Add explicit handling for HP softpaq exit code 1168 (ERROR_NOT_FOUND) in the driver extraction result classifier, with actionable remediation logging and Pester test coverage.

Purpose: HP softpaq extractions sometimes return exit code 1168 ("Element not found") even when driver files have been partially or fully extracted. Currently this falls into the generic "unknown exit code" default case, producing a non-actionable warning message. This fix adds a specific case that treats 1168 as a successful extraction (files likely present) with clear remediation guidance if the user needs to investigate.

Output: Updated FFU.Drivers module with 1168 handling, version bumps, and 4+ new Pester tests.
</objective>

1. In FFU.Drivers.psm1, function Get-DriverExtractionResult, within the 'HP' vendor switch (line ~205), add a new case for exit code 1168 BEFORE the default case. Insert it after the 3010 case (line ~231) and before the default case (line ~232):

```powershell
1168    {
    $result.Success = $true
    $result.Message = "HP ${DriverName} extraction returned exit code 1168 (ERROR_NOT_FOUND). " +
        "This typically indicates the softpaq could not locate expected registry entries or embedded files, " +
        "but driver files were likely extracted successfully. " +
        "Remediation: Verify extracted files exist in the destination folder. " +
        "If empty, re-download the softpaq from HP Support or try a different driver version."
}
```

Key design decisions:
- Success = $true: The driver files are typically present despite this error. Marking as failure would unnecessarily abort working extractions.
- Critical = $false (default): Not a critical error that should halt the build.
- Action = 'Continue' (default): The extraction loop will proceed normally, same as exit code 0.
- The message is ACTIONABLE: it explains what 1168 means, why it's OK, and what to do if files are actually missing.

# HP-01: Exit code 1168 handling
It 'Should classify HP exit code 1168 as Success (ERROR_NOT_FOUND)' {
    $result = $module.Invoke({
        Get-DriverExtractionResult -Vendor 'HP' -ExitCode 1168 -DriverName 'TestDriver'
    })
    $result.Success | Should -BeTrue

    $result.Action | Should -Be 'Continue'
}

It 'Should include ERROR_NOT_FOUND in 1168 message' {
    $result = $module.Invoke({
        Get-DriverExtractionResult -Vendor 'HP' -ExitCode 1168 -DriverName 'TestDriver'
    })
    $result.Message | Should -Match 'ERROR_NOT_FOUND'
}

It 'Should include remediation steps in 1168 message' {
    $result = $module.Invoke({
        Get-DriverExtractionResult -Vendor 'HP' -ExitCode 1168 -DriverName 'TestDriver'

It 'Should include driver name in 1168 message' {
    $result = $module.Invoke({
        Get-DriverExtractionResult -Vendor 'HP' -ExitCode 1168 -DriverName 'sp99999'
    })

}
