**Phase Context:** Phase 49 initiates the v2.0.0-alpha milestone — a complete rewrite of the UI layer from PowerShell/WPF to native C# WPF. The existing PowerShell modules (11 FFU.* modules + FFU.Common) remain unchanged; this phase focuses on creating the C# host application that can load and invoke those modules via the PowerShell SDK.

**Architecture Decision:** Use in-process PowerShell SDK (Microsoft.PowerShell.SDK 7.4.7) rather than out-of-process automation. This provides better performance and simpler debugging compared to launching pwsh.exe processes.

**Coexistence Strategy:** Both UIs coexist during the transition. FFUDevelopment/BuildFFUVM_UI.ps1 (PowerShell UI) continues to work unchanged. FFUBuilder.Desktop/ (C# UI) is a separate solution that references the same PowerShell modules.
</context>
