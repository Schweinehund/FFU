    Create Invoke-CatalogQueryWithRetry function in FFU.Updates.psm1. Follow the existing retry pattern from Get-KBLink (lines 388-412).

    **Function signature:**
    ```powershell
    function Invoke-CatalogQueryWithRetry {
        [CmdletBinding()]
        [OutputType([object])]
        param(
            [Parameter(Mandatory)]
            [scriptblock]$Query,

            [Parameter()]
            [string]$OperationName = 'Catalog query',

            [Parameter()]
            [int]$MaxRetries = 3,

            [Parameter()]
            [int]$BaseDelaySeconds = 10
        )
    }
    ```

    **Implementation:**
    1. Loop from attempt 1 to MaxRetries
    2. Execute Query scriptblock in try/catch
    3. On success, return result immediately
    4. On failure:
       - Log warning with attempt number and error message
       - If not last attempt, calculate delay with exponential backoff + jitter
       - Jitter: `$jitter = Get-Random -Minimum 0 -Maximum 3`
       - Delay: `$delay = ($BaseDelaySeconds * [math]::Pow(2, $attempt - 1)) + $jitter`
       - Sleep for delay seconds
    5. After all retries exhausted, log error and throw last exception

    **Add to FunctionsToExport in .psd1:**
    - 'Invoke-CatalogQueryWithRetry'

    **Do NOT export:** This is a helper function. Mark it as internal (do NOT add to FunctionsToExport). It will be used internally by Get-ProductsCab.
  </action>

  </verify>
  <done>Invoke-CatalogQueryWithRetry function exists with exponential backoff + jitter logic</done>
