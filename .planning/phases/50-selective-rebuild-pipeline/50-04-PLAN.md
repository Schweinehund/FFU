|----------|-------------|
| config JSON Disposition -> pipeline copy gate | The USB-Mode gate consumes Disposition strings from the config file to drive copy/skip decisions. |
| $AppsISOPath -> robocopy / Start-Process-class file op | A user-browsed Apps ISO path is split and passed to robocopy as source. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-07 | Tampering | Malformed Disposition value in config | mitigate | Gate validates `$disp -notin @('Reuse','Rebuild','Skip')` and forces Reuse with a warning before any switch routing (V5 control). No arbitrary string reaches execution. |
| T-50-08 | Tampering | Path traversal / injection via $AppsISOPath | mitigate | $AppsISOPath is gated by Test-Path before $CopyAppsISO is enabled; robocopy is invoked with Split-Path Parent/Leaf (no shell string concatenation, no -ArgumentList interpolation into Start-Process). robocopy treats inputs as literal paths, not a command line. |
| T-50-09 | Elevation of Privilege | Rebuild does not execute arbitrary artifacts | accept | This plan performs copy only — it does not execute any artifact. The Apps ISO is copied, never mounted/run here. N/A for arbitrary-execution. |
| T-50-SC | Tampering | npm/pip/cargo installs | accept | No package installs. |
