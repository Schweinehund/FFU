**Browse handler template** (repeat for all 7 with values from table below):
```powershell
$State.Controls.usbFFUBrowse.Add_Click({
    param($eventSource, $routedEventArgs)
    $window = [System.Windows.Window]::GetWindow($eventSource)
    $localState = $window.Tag
    $selectedPath = Invoke-BrowseAction -Type 'OpenFile' -Title 'Select FFU Image' -Filter 'FFU files (*.ffu)|*.ffu'
    if ($selectedPath) {
        $localState.Data.usbArtifactState.FFU.path   = $selectedPath
        $localState.Data.usbArtifactState.FFU.source = 'user'
        $localState.Controls.usbFFUPath.Text         = $selectedPath
        $localState.Controls.usbFFUStatus.Text       = 'Found (user path)'
        $localState.Controls.usbFFUStatus.Foreground  = 'Green'
        $localState.Controls.usbFFUStatus.FontStyle   = 'Normal'
        $localState.Controls.usbFFUInclude.IsEnabled  = $true

        # FFU-specific: re-extract metadata from user-selected file
        try {
            $metadata = Get-ArtifactMetadata -FFUPath $selectedPath
            if ($null -ne $metadata) {
                $localState.Controls.usbFFUVersion.Text = if ($metadata.WindowsVersion) { $metadata.WindowsVersion } else { '--' }
                $localState.Controls.usbFFUSKU.Text     = if ($metadata.SKU) { $metadata.SKU } else { '--' }
                $localState.Controls.usbFFUArch.Text    = if ($metadata.Architecture) { $metadata.Architecture } else { '--' }
            }
        } catch {
            if ($function:WriteLog) { WriteLog "USBBrowse: Failed to extract FFU metadata: $_" }
        }
    }
})
```

**1. usbCheckUSBDrives.Add_Click handler** -- replicate the existing btnCheckUSBDrives handler pattern (lines 199-221 area). Read that handler first to match the exact pattern:

```powershell
$State.Controls.usbCheckUSBDrives.Add_Click({
    param($eventSource, $routedEventArgs)
    $window = [System.Windows.Window]::GetWindow($eventSource)
    $localState = $window.Tag

    $localState.Controls.usbUSBDriveList.Items.Clear()
    $usbResult = Get-USBDrives
    $usbDrives = $usbResult[0]
    $usbDrivesCount = $usbResult[1]

    if ($usbDrivesCount -gt 0) {
        foreach ($drive in $usbDrives) {
            $localState.Controls.usbUSBDriveList.Items.Add($drive) | Out-Null
        }
        if ($function:WriteLog) { WriteLog "USB Mode: Found $usbDrivesCount USB drive(s)." }
    } else {
        if ($function:WriteLog) { WriteLog 'USB Mode: No USB drives found.' }
    }
})
```

**IMPORTANT:** Read the existing `btnCheckUSBDrives` handler in Register-EventHandlers first. Copy its exact `Get-USBDrives` call pattern. The function returns a tuple `($USBDrives, $USBDrivesCount)` -- use `$result[0]` and `$result[1]` to unpack. The ListBox item display should match whatever the Build tab's ListView uses.
