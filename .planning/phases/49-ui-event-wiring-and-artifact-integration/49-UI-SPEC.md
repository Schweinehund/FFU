## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | WPF Margin/Padding syntax | Usage |
|-------|-------|--------------------------|-------|
| xs | 4px | `Margin="4"` or `Margin="0,0,4,0"` | Icon gaps, inline label-to-value gaps |
| sm | 8px | `Margin="8"` or `Margin="0,0,8,0"` | Inter-row spacing within a card |
| md | 16px | `Margin="16"` or `Margin="0,0,16,0"` | Default element spacing between cards |
| lg | 24px | `Margin="0,0,0,24"` or GroupBox `Margin="0,0,0,15"` | Section breaks between GroupBoxes |
| xl | 32px | — | Layout gaps (not currently used in USB Mode tab) |

Exceptions:
- GroupBox separation: `Margin="0,0,0,15"` (15px) — matches existing Phase 48 XAML exactly; do not change to 16px
- Artifact card internal indent: `Margin="20,0,0,N"` — 20px left indent for status/path/size rows under card label
- Separator elements: `Margin="0,10"` — 10px top/bottom between artifact cards in a GroupBox
- Window outer grid: `Margin="10"` — established by existing layout
- TabControl padding: `Padding="10"` — established by existing layout

Source: Direct measurement from `BuildFFUVM_UI.xaml` lines 944–995 (USB Mode tab artifact card layout).

| Role | Value | WPF property | Usage |
|------|-------|-------------|-------|
| Dominant (60%) | `#FFFFFF` / OS default | Background (system) | Window background, tab content area — WPF default, not explicitly set |
| Secondary (30%) | `#888888` | `Foreground="#888888"` | Artifact card metadata labels (Status, Path, Size, Age, arch labels and values in idle state) |

Accent reserved for: Browse buttons (system button chrome), CheckBox tick (system style), RadioButton selection (system style). No custom accent hex value is used — the project relies entirely on OS/WPF system colors for interactive chrome.

**Dynamic foreground states for artifact card status TextBlock (`usbFFUStatus`, etc.):**
- Idle / pre-scan: `Foreground="#888888"` with `FontStyle="Italic"` — text: `(scanning...)` or `(not scanned)`
- Found: `Foreground="Green"` — text: `Found`
- Missing: `Foreground="OrangeRed"` — text: `Missing`
- User-overridden and file verified: `Foreground="Green"` — text: `Found (user path)`
- User-overridden but file not found: `Foreground="OrangeRed"` — text: `Missing (user path)`

Source: Phase 48 XAML establishes `#888888` and `#666666`; `Green`/`OrangeRed` for status are standard WPF named colors consistent with existing hypervisor status at line 134 (`Foreground="Gray"`).

## Interaction Contract

This section describes state machine transitions and interaction sequences required for Phase 49. Executor must implement exactly these behaviors.

### Mode Switch — USB Mode activation (D-25)

Trigger: `rbUSBMode.Checked`

Sequence (order-dependent — execute in this order to prevent flicker):
1. Set `Visibility="Collapsed"` on: `tabVMSettings`, `tabWindowsSettings`, `tabUpdates`, `tabApplications`, `tabM365AppsOffice`, `tabDrivers`, `tabBuild`
2. Set `Visibility="Visible"` on `usbModeTab`
3. Set `MainTabControl.SelectedItem = usbModeTab`
4. Call `Invoke-USBArtifactScan -State $localState`
5. Set `btnRun.Content = 'Create USB'`

### Mode Switch — Full Build activation (D-26)

Trigger: `rbFullBuild.Checked`

Sequence:
1. Set `Visibility="Visible"` on all 7 Full Build tabs listed above
2. Set `Visibility="Collapsed"` on `usbModeTab`
3. Set `MainTabControl.SelectedItem = tabVMSettings`
4. Set `btnRun.Content = 'Build FFU'`

### Artifact Scan (D-01 through D-05)

Trigger: Mode switch to USB Mode OR `usbRescanArtifacts` button click.

Pre-condition: `txtFFUDevPath.Text` must be a non-empty path that exists on disk. If not, log warning and return without scanning — do not show an error dialog at scan time.

Scan behavior:
- For each artifact card where `source != 'user'`: set status TextBlock to `(scanning...)` with `Foreground="#888888"` and `FontStyle="Italic"` before calling `Find-FFUArtifacts`
- For each artifact card where `source == 'user'`: leave status and path TextBlocks unchanged; re-verify file existence at end
- Call `Find-FFUArtifacts -FFUDevelopmentPath $ffuDevPath` (synchronous, UI thread — per D-02)
- After scan returns, update each auto-detect card:
  - Found: set status to `Found` with `Foreground="Green"` and `FontStyle="Normal"`; set path TextBlock to full path; set size and age TextBlocks
  - Missing: set status to `Missing` with `Foreground="OrangeRed"` and `FontStyle="Normal"`; set path TextBlock to `(not found)`
- For FFU artifact specifically: also populate `usbFFUVersion`, `usbFFUSKU`, `usbFFUArch` from `ArtifactResult.Metadata`
- After all cards updated: enable Browse buttons (`IsEnabled=$true` for all 7); enable CheckBoxes only for Found artifacts (`IsEnabled=$true`); leave CheckBoxes for Missing artifacts `IsEnabled=$false`

### Browse Override (D-06 through D-09)

Trigger: `usbFFUBrowse` (or any of the 7 Browse buttons) click.

Behavior:
1. Call `Invoke-BrowseAction` with appropriate `Type` and `Filter` per artifact type (see table below)
2. If user selects a path: update `$State.Data.usbArtifactState[type].path = $selectedPath` and `source = 'user'`
3. Update path TextBlock with selected path
4. Set status to `Found (user path)` with `Foreground="Green"` and `FontStyle="Normal"`
5. Enable the artifact's CheckBox
6. For FFU artifact: re-run `Get-ArtifactMetadata` on the selected file and update version/SKU/arch TextBlocks

Browse dialog parameters per artifact type:

| Artifact | Button | Type | Filter |
|----------|--------|------|--------|
| FFU Image | `usbFFUBrowse` | `OpenFile` | `FFU files (*.ffu)|*.ffu` |
| Deploy ISO | `usbDeployISOBrowse` | `OpenFile` | `ISO files (*.iso)|*.iso` |
| Drivers | `usbDriversBrowse` | `Folder` | n/a |
| PPKG | `usbPPKGBrowse` | `OpenFile` | `Provisioning packages (*.ppkg)|*.ppkg` |
| Unattend | `usbUnattendBrowse` | `OpenFile` | `XML files (*.xml)|*.xml` |
| Autopilot | `usbAutopilotBrowse` | `OpenFile` | `JSON files (*.json)|*.json` |
| Apps ISO | `usbAppsISOBrowse` | `OpenFile` | `ISO files (*.iso)|*.iso` |

### Rescan (D-04, D-07)

Trigger: `usbRescanArtifacts` button click.

Behavior: Re-runs `Invoke-USBArtifactScan`. For artifacts with `source='user'`: only re-verify file existence (update status to `Found (user path)` or `Missing (user path)`). Does not clear user-selected paths.

### Create USB Pre-Launch Validation (D-19 through D-20)

Trigger: `btnRun` click while `rbUSBMode.IsChecked = $true`.

Validation gates (in order — stop at first failure, show dialog):
1. `usbFFUStatus` must be `Found` or `Found (user path)` AND `usbFFUInclude.IsChecked = $true` → else show "An FFU image is required…" dialog
2. `usbDeployISOStatus` must be `Found` or `Found (user path)` AND `usbDeployISOInclude.IsChecked = $true` → else show "The WinPE Deploy ISO is required…" dialog
3. At least one item selected in `usbUSBDriveList` → else show "Select at least one USB drive…" dialog

If all gates pass: launch `BuildFFUVM.ps1 -USBOnlyMode` via `Start-ThreadJob` using same pattern as Full Build. Set `btnRun.Content = 'Cancel'`.

### Reset to Idle (D-17)

`Reset-FFUUIToIdle` must check `$State.Controls.rbUSBMode.IsChecked`:
- `$true`: set `btnRun.Content = 'Create USB'`
- `$false` (or null): set `btnRun.Content = 'Build FFU'`

### Config Persistence (D-22 through D-24)

On save (`Build-UIConfiguration`):
- Write `ActiveMode`: `'USBMode'` if `rbUSBMode.IsChecked`, else `'FullBuild'`
- For each artifact where `$State.Data.usbArtifactState[type].source == 'user'`: write path to `USBMode.Artifacts.{Type}.Path`

On load (`Update-UIFromConfig`):
- Read `ActiveMode`: set `rbUSBMode.IsChecked = $true` or `rbFullBuild.IsChecked = $true`; fire the Checked handler (triggers scan if USB Mode)
- For each `USBMode.Artifacts.{Type}.Path` that is non-empty: set `$State.Data.usbArtifactState[type].path` and `source = 'user'`; update path TextBlock; scan will verify existence

## Per-Artifact State Tracking (Claude's Discretion)

Internal state for each artifact is tracked in `$State.Data.usbArtifactState` as a hashtable of PSCustomObjects:

```powershell
$State.Data.usbArtifactState = @{
    FFU        = [PSCustomObject]@{ source = 'auto'; path = $null }
    DeployISO  = [PSCustomObject]@{ source = 'auto'; path = $null }
    Drivers    = [PSCustomObject]@{ source = 'auto'; path = $null }
    PPKG       = [PSCustomObject]@{ source = 'auto'; path = $null }
    Unattend   = [PSCustomObject]@{ source = 'auto'; path = $null }
    Autopilot  = [PSCustomObject]@{ source = 'auto'; path = $null }
    AppsISO    = [PSCustomObject]@{ source = 'auto'; path = $null }
}
```

Initialized in the state setup block before `Register-EventHandlers` is called. Keys match the `ArtifactType` enum values from `FFU.ArtifactScanner.Classes.ps1`.
