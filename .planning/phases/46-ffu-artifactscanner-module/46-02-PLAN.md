       function Find-FFUArtifacts {
           [CmdletBinding()]

               [string]$FFUDevelopmentPath

    3. **Create manifest:** `$manifest = New-ArtifactManifest; $manifest.BasePath = $FFUDevelopmentPath`

    4. **7 private scanner helper functions** (each wrapped in try/catch per Pattern 3 from RESEARCH.md):

       a. `Find-FFUFiles` - Scan `$FFUDevelopmentPath\FFU` for *.ffu files. For each: create ArtifactResult, set FilePath/FileSizeBytes/LastWriteTime/AgeDays. Sort by LastWriteTime descending, mark first as IsPrimary. Call `Get-ArtifactMetadata -FFUPath $path -WimMountAvailable $wimMountAvailable` for each. If no .ffu files: single ArtifactResult with Status=Missing.

       b. `Find-DeployISO` - Check for `WinPE_FFU_Deploy_x64.iso` and `WinPE_FFU_Deploy_arm64.iso` in root. Return first found as ArtifactResult with Status=Found. If none: Status=Missing. Parse architecture from filename via regex `WinPE_FFU_Deploy_(.+)\.iso`.

       c. `Find-Drivers` - Check `$FFUDevelopmentPath\Drivers` folder exists. If exists: `Get-ChildItem -Recurse` for FileCount, TotalSizeBytes. AgeDays from newest file LastWriteTime (not folder -- per Pitfall 6). If folder missing or empty: Status=Missing.

       d. `Find-PPKGFiles` - Scan `$FFUDevelopmentPath\PPKG` for *.ppkg. Each file gets an ArtifactResult. If none: single result with Status=Missing.

       e. `Find-UnattendFiles` - Check specifically for `unattend_x64.xml` and `unattend_arm64.xml` in `$FFUDevelopmentPath\Unattend` (per BuildFFUVM.ps1 lines 1504-1515). Each found file gets ArtifactResult. If none: single result with Status=Missing.

       f. `Find-AutopilotFiles` - Scan `$FFUDevelopmentPath\Autopilot` for *.json (per BuildFFUVM.ps1 line 2107). Each file gets ArtifactResult. If none: single result with Status=Missing.

       g. `Find-AppsISO` - Check `$FFUDevelopmentPath\Apps\Apps.iso` exists. Existence + file size only, no ISO mount. Status=Found or Missing.

    5. **Staleness calculation** (in each scanner): `$ageDays = [int][Math]::Floor(([DateTime]::Now - $fileInfo.LastWriteTime).TotalDays)` -- use `[DateTime]::Now` not `Get-Date`.

    6. **Readiness summary** (after all scans):
       - Count FoundCount, MissingCount, ErrorCount across all artifact results
       - `$manifest.IsReady` = true if at least one FFU found AND DeployISO found AND ErrorCount is 0

    7. **Automatic compatibility check**: Call `Test-ArtifactCompatibility` on the manifest (implemented in Task 2) and assign result to `$manifest.Warnings`.

       - Test all scenarios listed in behavior block

    NOTE: Use `Get-ChildItem -ErrorAction SilentlyContinue` for folder scans to handle missing directories gracefully. Use `[System.IO.FileInfo]` for direct file properties where possible (ThreadJob safe).
