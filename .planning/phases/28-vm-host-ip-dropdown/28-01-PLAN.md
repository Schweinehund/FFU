  <action>
Add a new function `Get-HostNetworkAdapters` after the existing `Get-VMwareHostIPAddress` function (after line 160).

The function should:
1. Use `Get-NetAdapter -Physical -ErrorAction SilentlyContinue | Where-Object { $_.Status -eq 'Up' }` to get physical adapters
2. For each adapter, get IPv4 address via `Get-NetIPAddress -InterfaceIndex $adapter.ifIndex -AddressFamily IPv4`
3. Filter out APIPA (169.254.x.x) and loopback (127.x.x.x) addresses
4. Return PSCustomObject array with properties:
   - IPAddress (string)
   - AdapterName (string - from $adapter.Name)
   - Description (string - from $adapter.InterfaceDescription)
   - DisplayText (string - format: "$IPAddress ($AdapterName - $Description)")
   - InterfaceIndex (int)
   - IsPrimary (bool - true if adapter has default gateway)
5. Mark primary adapter using `Get-NetRoute -DestinationPrefix '0.0.0.0/0'` to find default gateway interface
6. Use WriteLog for diagnostics (consistent with existing patterns)
7. Include error handling with try/catch, return empty array on failure

Function signature:
```powershell
function Get-HostNetworkAdapters {
    [CmdletBinding()]
    [OutputType([PSCustomObject[]])]
    param()
```

Also add the function to the module's Export-ModuleMember statement at the bottom of the file.
